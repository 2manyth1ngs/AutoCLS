## 0. TL;DR

1. **主判据红灯**：最优档（iters=60）相对重复差 P95 = **29.8%**，红线（>15%）的
   2 倍；三档全红（30: 38.1% / 60: 29.8% / 290: 77.5%）。**预测路线的核心假设
   （"Ridge 无 SVM 随机层 → 噪声显著更小"）不成立。**
2. **机制结论比判定更重要**：噪声的上游是**预训练轨迹随机性**，不是下游评估协议。
   Ridge 全程确定性（无采样、无迭代随机），跨 weight_seed 的 MSE 抖动只能来自
   "同一 CLS、不同初始化 → 不同表征"。分类噪声的根因在预测任务上**原样存在**——
   换任务类型绕不过它。
3. **噪声结构与分类同构**：重尾（rel P95/med = 3.1–6.9，分类 HW 3.8）；噪声与
   CLS 破坏性强相关（Spearman(mean MSE, CV) ρ = 0.88/0.73/0.69，全显著）——
   UniMiB"越破坏越吵"（ρ 0.52）的更强版。好配置端确实安静（每档最优 3 CLS 的
   CV 1.7–4.4%），但 P95 口径（与分类 δ 标定同式）被坏配置尾部支配。
4. **相对量对照**（判据的可比口径）：分类 HW 工作点 abs P95 0.110 ≈ 相对 12–20%；
   预测最优档相对 P95 29.8%——**更差**。中位也没好：预测 rel med ≈ 10%（三档
   9.8–11.3%）vs 分类 abs med 0.029 ≈ 相对 3–5%。
5. **预测对账 1✓/2✗**：P3（噪声~破坏性正相关）✓；P1（落中间档）✗（更差，红）；
   P2（290 档噪声最低）✗（**最高**，77%——长训让破坏性配置的发散更不稳定，
   20be4f74@290 的 MSE 均值 0.336、CV 48%）。外推失手方向与既往元教训一致。
6. 成本：墙钟 **34.8 min**（点估 30 / 保守 90）；90/90 满格零 null 零 OOM 零重复。

## 3. per-CLS 结构（诊断，不参与判定）

- 三档 Spearman(cell mean MSE, cell CV)：**0.879 / 0.733 / 0.685**（p ≤ 0.029）
  ——噪声很大程度是 CLS 属性（越破坏越吵），比 UniMiB（0.52）更强。
- 每档最安静的 3 个 CLS：CV 1.7–4.4%（30）、1.8–3.9%（60）、1.8–2.6%（290）；
  最吵的 2 个 CLS：CV 19–21%（30）、16–19%（60）、27–48%（290）。
  连续谱、无天然分界（outlet_y §2 同款），且"哪个 CLS 吵"跨 iters 档不稳定
  （4f7d4135：30 档 CV 7.1% → 60 档 1.8% → 290 档 27.2%）——per-CLS δ 在预测上
  同样没有可靠标定基础。

## 6. 推论

1. **转预测不解决噪声问题**——判定依预注册红灯档行动：重新评估投入。
2. 机制上这不是"预测碰巧也不行"：Ridge 把评估层随机性压到零后，噪声只剩
   预训练轨迹一个来源，而它就是分类噪声的根因。**任何"换下游任务类型"的方案
   都继承这层噪声**；能改变它的只有（a）k>1 平均（成本 ×k，两轮均判不经济）、
   （b）让预训练轨迹本身稳定（SWA 已试：部分改善、判不是出路）、
   （c）换 R' 的定义使其对表征扰动不敏感（未探索，无现成方案）。
3. 附带信号侧坏消息（非本轮判定对象，仅记录）：几乎未训练的表征（30 iters）
   + 协变量 + Ridge 已达论文收敛值量级（0.066–0.075 vs TS2Vec 0.062）——ETTh1
   univar 的可预测性大头在协变量与线性结构里，CLS 分辨空间疑似又是"破坏排序"
   主导（cell 均值 0.066–0.131，好配置端挤在 0.066–0.075）。若未来重启预测路线，
   信号侧探针须先排除这一贴顶同构。

## 7. Limitations

1. 单数据集（ETTh1）、单 horizon（Q=48）、单变量口径；10 shared CLS 不含 random
   采样（分类轮 random 更破坏、噪声只会更大，方向不利于翻案）。
2. iters ≤ 290；更长训练在 60→290 的走向（恶化）下无翻案先验，但未实测。
3. 相对量分母 = cell 三 rep 均值（预注册）；若按"好配置端 MSE 水平"归一，
   坏配置的相对噪声还会更大——分母选择只会让结论更严不会更松。
4. 预训练实例构造（INST_LEN=256/STRIDE=24 滑窗）是本项目 trainer 语义的必要适配；
   官方长序列直喂（batch 2）未对照——但那只会改变噪声的具体数值，改不了
   "轨迹随机性 → 表征抖动"的因果链（rep 间唯一差异是 weight_seed）。
5. k=3 的 P95 估计自身方差不小（30 对/档）；但三档同向红、且中位也差，
   结论对估计误差稳健。
