# 排查二（encoder 架构）：与 TS2Vec 官方实现逐项一致，消融拉不动基线——贴顶是协议固有强度，encoder 排除

`tests/test_encoder_ablation.py`（12 单测）｜ 数据：`ablation_cache.jsonl`（100 行满格）
｜ **test 触碰数不变**（UCI-HAR 只用 train 侧 + 跨受试者 val）

## 0. TL;DR

1. **排查 A（逐项对照）**：`autocls/encoders/dilated_cnn.py` 与 TS2Vec 官方代码
   （github.com/zhihanyue/ts2vec，逐行拿到原文）**eval 前向路径功能等价**。
   重点怀疑项全部排除：**初始化两边均为 PyTorch 默认（官方无任何自定义 init）**、
   pooling 同为时间维 max、结构逐行同构。差异全在训练期且多为有意设计。
2. **排查 B（架构消融，10 配置 × 5 种子 × 2 数据集）**：深度 10→1 层基线**纹丝不动**
   （0.894 vs 0.894）；维度 320→32 只 −0.05；pooling max→last 只 −0.09（仍 0.80）。
   唯一跌破 0.75 的 nores（去残差）是**退化态**：两数据集全部塌到常数预测
   （acc 恰等于 val 多数类占比、5 种子 std=0.0000），命中预注册的
   "削弱到什么都学不到"排除条款。
3. **核心结论：encoder 架构不是贴顶成因**。贴顶是「残差连接的随机卷积特征 +
   max-pool + SVM-RBF」这一协议在 HAR 类数据上的固有强度——AutoCL/TS2Vec 原版
   完全同协议。**排查 C 按预注册条件跳过**（A 无实现差异可修正；B 唯一候选被
   对照排除）。目标池不可评结论坐实，安心走论文路线。

## 1. 排查 A：差异清单（逐项，来源标注）

来源：TS2Vec 官方 `models/dilated_conv.py`、`models/encoder.py`、`ts2vec.py`、
`tasks/_eval_protocols.py`、`tasks/classification.py`（GitHub 原文逐行确认）；
AutoCL 论文 arXiv 2403.12641 附录 B.1/B.3（无公开代码，只有论文级描述）。

| 维度 | 本项目 | TS2Vec 官方（代码确认） | 差异 | 影响 |
|---|---|---|---|---|
| 层数/dilation | 10 层 + 输出层，dilation=2^i | 同（`channels=[hidden]*depth+[output]`，dilation=2^i） | 无 | — |
| 残差连接 | ConvBlock 双卷积 + residual/1×1 projector | 逐行同构 | 无 | — |
| 卷积核 | 3，SamePadConv 偶感受野裁尾 | 同（多一个未用的 `groups=1` 参数） | 无 | — |
| 激活 | GELU（残差前置） | 同 | 无 | — |
| Norm | 无 | 无（原版就没有任何 norm 层） | 无 | — |
| input_fc | `nn.Linear(C, 64)` | 同 | 无 | — |
| **初始化** | PyTorch 默认（无自定义） | **同——官方 `__init__`/`fit` 均无任何显式初始化**（代码确认） | **无** | ⚠️ 排查前的头号怀疑项，排除：随机初始化基线两边同分布 |
| 表征维度 | 320 | 320（默认）；AutoCL B.3 原文同 320 | 无 | — |
| **pooling** | 时间维 max（`z.max(dim=1)`） | 分类协议 `encoding_window='full_series'` → `F.max_pool1d(kernel=T)`，**等价** | **无** | AutoCL B.1 未写 pooling（论文未给全，按 TS2Vec 语义补全） |
| dropout | 无 | `repr_dropout(p=0.1)`——**仅训练期**，eval 恒等 | 训练期 | 不影响任何基线；有意移除（前向确定性，dilated_cnn.py 文档记明） |
| 训练期 mask | 无（掩码是 CLS 搜索字段） | 默认 binomial mask——**仅训练期**，eval 走 all_true | 训练期 | 同上，项目设计使然 |
| SWA | 无（评估用原始权重） | `encode` 用 `AveragedModel`（逐 iter 等权平均） | **训练期，此前未记录** | 不影响 iters=0 基线；对训练后 R' 或有平滑作用。M1 无 SWA 已复现论文 GGS 0.9372≈0.937，故非急务 |
| SVM 网格 | C∈{1,10,100}，cv=3，≤3000 抽样选 C 后全量拟合 | C∈{1e-4…1e4,∞}，cv=5，>10000 抽样（**且只在抽样上拟合**） | 评估器 | 排查一已验证评估路径（test 随机基线 0.9183、M1 同源）；网格差异不改贴顶结论 |
| NaN 处理 | NaN 时间步置零 | 同 | 无 | — |

**结论**：eval 前向 = 逐位同构；「初始化不同抬高基线」假设被代码原文直接否证。

## 2. 排查 B：架构消融（iters=0 随机初始化基线）

口径：UCI-HAR 全量 6 类 9 通道，跨受试者 val（留出组 {8,17,21,25}，n_fit=5886/
n_val=1466）；Handwriting 全量 26 类分层 70/30 对照（n_fit=700/n_val=300，
chance≈0.038）。一次一因子；base 变体与 `build_encoder` 默认逐位同权重
（单测保证）；base 复现参照 0.8935 vs 0.8911 ✅。

| 配置 | UCI-HAR（Δvs base） | Handwriting（Δvs base) | 判读 |
|---|---|---|---|
| base（10 层/320/max/残差） | 0.8935±0.006 | 0.4893±0.006 | 参照复现 ✅ |
| depth6 / depth3 / **depth1** | 0.896 / 0.892 / **0.894**（≈0） | 0.489 / 0.489 / 0.441 | **深度完全不支撑贴顶** |
| dims128 / 64 / **32** | 0.893 / 0.881 / **0.842**（−0.05） | 0.438 / 0.423 / 0.343 | 维度影响轻微；"320 维随机核过强"不成立——32 维仍 0.84 |
| pool_mean / **pool_last** | 0.877 / **0.802**（−0.09） | 0.298 / 0.239 | max-pool 非罪魁：连"只取最后时间步"都 0.80 |
| **nores**（去残差） | **0.1965±0.0000** | **0.0533±0.0000** | **退化态**：acc 恰等于多数类占比（HAR 0.2012 / HW 0.0533）、5 种子零方差 → 特征不含输入信息，常数预测 |

要点：

- **唯一 <0.75 的配置（nores）被预注册对照条款排除**——它把 Handwriting 也打到
  chance，是"什么都表示不了"而非"修好过强"。机制：无残差时 11 个 GELU→conv
  块在随机初始化下把信号逐层冲刷成输入无关的常数；**残差通路正是随机特征
  可用性的来源**（同时也是可训练性的来源，去掉它没有任何意义）。
- 其余全部配置 ≥0.80，其中贴近协议的（depth/dims≥64）全部 >0.85 →
  按预注册判读：**encoder 架构不是主因**。dims32/pool_last 落在 0.80–0.84
  灰区，但它们是"更弱的另一套协议"而非"向原版修正"（原版就是 320+max），
  且降到 0.80 也远开不出 GGS ±0.03 噪声带之外的学习空间。

## 3. 对反证的解释（Handwriting 为什么能 +0.397）

同一 encoder、同一协议下，Handwriting 随机基线只有 0.49（26 类，chance 0.038），
离顶 0.51——随机残差卷积特征在需要精细时序形状判别的数据上**不够用**，预训练
质量因此可测。HAR 类数据（9 通道惯性信号、6 个粗粒度活动类）的类结构从几乎
任意随机投影里都能被 RBF SVM 恢复（深度 1 层、维度 32、连 last-timestep 读出
都 ≥0.80），学习空间被数据本身抹平。**"encoder 过强"是数据集相对属性，
不是架构缺陷**——这正是源池筛选（headroom 判据）该负责的事，与既有结论
（baseline_probe"贴顶是源池主流"、full-iters 判定 D、目标池三连灭）完全自洽。

## 4. 剩余不确定性（如实记录）

- **SWA 缺失**是本次新发现的训练期差异（此前未记录在 dilated_cnn.py 文档里）：
  不影响本次结论（iters=0 无关、M1 已复现论文量级），但若将来重启训练侧实验，
  可作为 R' 噪声压缩的候选手段单独评估。
- SVM C 网格缩小是已知有意简化；排查一的 test 直验已覆盖其影响面。
- 本消融只测了随机初始化端；"某弱化配置下 GGS 是否有增益"未测（排查 C），
  因触发条件（A 有可修正差异 / B 有非退化的 <0.75 配置）均未命中，按预注册跳过。
