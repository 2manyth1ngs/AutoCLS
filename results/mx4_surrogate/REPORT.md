# MX-4 WP2 报告：字段结构化代理 vs T-CLSC（零 GPU，7 折 LODO）

协议：`PROTOCOL.md`（§0 声明探索读数已看过）。脚本：`scripts/37_surrogate_loo.py --analyze`（产物 `analysis.json`、`tables.md`）。
模块：`autocls/search/surrogate.py`（`FieldSurrogate` / `pairwise_matrix` / `field_hamming` / `in_hull`），
编码：`autocls/space/cls_encoder.py` 新增 `mode="binned"`（默认 scalar 逐位不变）。数据：`results/mx3_pq/`（只读）。

## 0. 一句话结论

读数码 **SUR-WIN**：一个在字段编码上拟合 within-task z 分数的 GBDT（每折 1 s，不需要 E / SetTF / 配对 label），
LODO 配对准确率 0.780 vs T-CLSC 0.735（同口径，5/7 折赢），regret@1 0.056 vs 0.074（p=7.3e-03）。
字段主效应清楚：**temperature 是破坏开关**（分组置换 ΔMSE 0.28，是第二名 sim_func 0.17 的 1.7×），其后是 sim_func / norm / freq_mask；
temporal / cross_scale / pool / adj_neighbor / loss_type 五个字段平均惰性。**S3 不过**：代理对目录外（进化）候选系统性高估
（预测 z +0.57 vs 真 +0.05，到训练集的字段汉明距离中位 8 vs 目录 3），bag-10 的 LCB 只把高估砍掉 44%、合并 Spearman 只 +0.017，
信任域过滤反而更差（0 条进化行在半径 3 内）——**开放空间搜索不能靠更好的代理立项，必须配目标侧真评估（WP1 的 SH）**。

## 2. 字段主效应（全 8 数据集 2700 行拟合；分析用）

hgb_binned 按字段分组置换 ΔMSE（重要性）与 ridge_binned 档内去均值系数极差：

| 3 | norm | 0.094 | 0.414 | none (+0.22) → l2 (−0.19) |

| 13 | crop | 0.020 | 0.354 | 0.3 (+0.19) → 0.95 (−0.17) |

| 17 | temporal | 0.010 | 0.015 | — |
| 18 | adj_neighbor | 0.007 | 0.114 | — |
| 19 | instance | 0.000 | 0.000 | 常量 |

读法：
- 三个"损失几何"字段（temperature / sim_func / norm）合计占分组重要性的 55%；温度 ≥10 是 65% 随机配置破坏性的主因。
- 8 个 ratio 字段的档位效应是**非单调**的（如 freq_mask 0.95 最好、0.8 最差；jitter 0.6 好、0.4 差），ridge 的逐档系数在 11 档 × 2700 行下
  噪声大（相邻档差 0.6 个 z 不可信），只能读"哪个字段有效应"，不能读"哪一档最好"——论文里用分组重要性排名，不要用逐档表。
- 配对构造块（temporal / cross_scale / pool / adj_neighbor）与 loss_type 平均惰性（末 6 位）：在这个 encoder + 切片协议下，
  AutoCL 空间里的层级/时间对比维度对下游 SVM 准确率没有可测的平均效应。P2 的"惰性五字段在末 8 位"命中；top-3 里多了 emb_jitter，
  P2 整体记 ✗。

## 3. 目录外诊断（进化 CLS 378 行，21 实例；LODO 模型 + bag-10）

| 量 | 目录候选 | 进化候选 |
|---|---:|---:|
| 预测 z − 真 z（高估量） | −0.035 | **+0.523** |
| 到训练集字段汉明距离中位 | 3.2 | **8.1** |
| 落在半径 3 信任域内的比例 | 0.50 | **0.00** |
| bag-10 预测 std 均值 | 0.165 | 0.228 |
| Spearman（预测 vs 真） | 0.448（仅目录） | 0.234（进化⊕目录合并） |

修正臂（合并 Spearman / 进化行高估量）：plain 0.234 / 0.523 → LCB(κ=1) 0.252 / 0.295 → 信任域过滤 0.175 / —。
**S3 不过**（Spearman +0.017 < 阈；高估降 44% < 50%）。P3 ✓（高估 ≥0.5、汉明 ≥4）、P4 ✓（LCB 提升 <0.10）。

读法：进化搜索把候选推到离训练分布 8 个字段远的角落（进化行 temporal 100%、emb_mask 均值 0.84、point_mask 0.08——MX-3 复算），
代理在那里的输出是外推；bagging 的 std 只涨 38%，远不足以反映外推误差（"自信的错"），信任域一刀切又把所有进化行都砍掉。
这是 MX-3 D3（5/21）失败的机制，与用的是 T-CLSC 还是 GBDT 无关。**结论**：开放空间搜索若要立项，形态只能是
"代理提名 + 目标侧真评估回灌（BO 式迭代）"，而不是一次性零样本外推；本轮不立项。

## 4. 对下游的建议

- 零样本排序器 = `hgb_binned`（或 hgb_scalar，等价），配 WP1 的先验：shared 目录按先验、目录外按代理（WP1 的 hybrid 臂）。
- 空间剪枝规则（供部署/论文）：temperature ≤ 1；sim_func ≠ cosine；norm = none 优先；ratio 字段避开极端档；
  配对构造块可固定（惰性）——把 4.7×10¹² 的空间剪到只剩有效应的 13 个字段。
- 不在开放空间做零样本外推；候选生成限于信任域（汉明 ≤3 于源池已评估配置），且必须过 SH 真评估。

## 5. Limitations

- 主效应在切片协议 + SVM-RBF + bs128 @{60,120,290} 口径下测得，不能直接外推到全量官方协议（WP3 再验）。
- 逐档系数噪声大（11 档 × 8 字段），只报字段级排名。
- T-CLSC 对照用名次→得分口径，与 MX-3 REPORT 的模型输出口径相差 0.011。
- HMD 有 4 个实例无 δ 存活对（δ@60/120 = 0.19，评估集 24–74），逐折表按存活实例平均。
