# 破坏矩阵报告（2026-08-30，协议先行 commit 25d5014；零 GPU）

数据：Panel A = @290 k1（16 UEA × 2 任务 × shared 10，配对 320/320 满格）；
Panel A' = @290 **k=3**（13 UEA，阶段1 SNR 闸噪声缓存 780 行 → 260 cell 均值）；
Panel B = 工作点（HW@60 + UM@30，280 条）。数值 `analysis.json`。

## 0. TL;DR（三层判读）

1. **形式判读：established**（预注册门 TDS≥0.25 且 mixed≥3——A 面板 0.71/8、
   A' 面板 0.83/9，全过）。**但补充的零模型校准显示预注册统计量混淆了两种
   效应**，诚实结论须拆开：
2. **坐实的一半（p<0.001）：数据集级脆弱度差异巨大且显著。** 同样 10 条
   shared CLS，@290 的破坏率从 NATOPS 0.75 / Ethanol 0.50 / SCP2 0.45 一路
   到 SCP1 / MotorImagery / HMD 的 **0.00**（A' k3 口径）。cls_only 零模型下
   ds 份额 p=0.000。**"这个数据集上策略空间有多毒"是真实的、大幅度的、
   随任务变的量**——E 有明确的可预测目标。k3 面板中 ds 份额（0.26→0.38）
   随噪声下降而**上升**、CLS 固有份额（0.29→0.17）下降——去噪后任务依赖
   更突出而非更弱。
3. **未坐实的一半：细粒度翻转图（哪条 CLS 在哪个数据集上翻）。** additive
   零模型下交互份额 p=0.27（k1）/0.45（k3）——每格仅 2 任务的分辨率下，
   观测交互与抽样噪声不可分；mixed CLS 8–9/10 同样被"主效应+噪声"完整解释
   （零模型自产中位 8）。**未证实 ≠ 证伪**：检验把任务间真实异质也算进噪声，
   偏保守；分辨率瓶颈（2 任务/格）是可解的。
4. **Panel B 佐证（P4 ✓）**：工作点口径 UM 0.14 vs HW 0.01，与已知 strict
   份额差（66% vs 5%）同向；但仅 2 数据集、低破坏率，不参与主判。
5. L 对齐失败（ρ=−0.18~−0.22，n.s.）：脆弱度不由序列长度单一解释——
   对 E 是好消息（信号不可被一个元数据字段替代），对可解释性是待办。

## 2. 方法与诚实度说明

- 预注册门（TDS、mixed）形式上全过，但两个统计量都同时吃 ds 主效应与
  交互——**零模型校准（post-hoc、稳健性性质）是更锋利的仪器**，本报告
  以它给出的拆分为准。按时间顺序如实记录：先按协议判 established，
  后校准降精度。
- 破坏判定 k=1（A）/k=3 均值（A'）+ 基线带（5 种子 2σ）；两面板同向。
- 检验保守性：additive 零模型把任务间真实差异计入噪声——交互"不可分"
  是权力不足，不是零证据。

## 4. 对抓手三的含义（供拍板）

1. **立项基础成立，但主张校准为"脆弱度水平预测"**：
   零样本任务感知的第一层 = 给未见数据集预测"策略空间在此的毒性水平/
   安全边界"（0→0.75 的真实跨度、E 的数据集分离 7×、幅度天然过 δ）。
   这一层证据已够写进设计。
2. **细粒度翻转图留作升级项**，解锁它需要每数据集更多任务：现有 @290
   缓存只有 2 任务/数据集。若立项，设计一个"宽任务面板"（4–6 个跨脆弱度
   数据集 × 8–16 任务 × shared+random CLS × k≥1）直接检验交互——贴顶
   数据集在此 label 类型下就是合格产地，成本与老造 label 同量级。
3. 与抓手二的耦合确认：脆弱度差异在 **UEA 池内部就已巨大**（不必等新池），
   但翻转图的检验受益于池异质化（L/域散布越大，交互越可能浮出噪声）。

## 5. Limitations

1. 交互检验功效不足（2 任务/格）；"未证实"对翻转图是开放问题。
2. A 面板 k=1 破坏标志含单种子噪声（A' k3 主判可部分抵消；两面板同向）。
3. @290 与工作点两口径破坏率差 3×（0.24 vs 0.07）——破坏是 iters 的函数
   （0.5 探针 P4 同款规律），feasibility label 必须绑定训练量口径。
4. 脆弱度与可学习性纠缠（§1 注）；三态目标变量设计待抓手三协议解决。
5. 零模型校准为 post-hoc（§2 如实记录）。
