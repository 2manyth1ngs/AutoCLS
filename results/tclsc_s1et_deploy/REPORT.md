## 4. 读法

1. **切片口径训练的比较器在官方目录上的失败模式是外推，不是 E**：任务盲 T-CLSC 与 E_T T-CLSC 都把提名配置抬进前 6、把 oracle 压到末尾；限域后任务盲 ≈ 先验、E_T 超先验。
   这与 MX-4 关键判负 (b)"任何代理对目录外候选系统性高估"完全一致，也是 WP8-BO 的同一堵墙。
2. **限域后 E_T 的增益落在先验名单失败的两个靶上**：HW（先验把 0.542 / 0.546 排到第 8/9，E_T 把 0.542 排进前 6）、Ethanol（0.297 vs 0.274）——正是 WP3 DEPLOY-DEAD 的两个未追平靶。
   其他四靶 E_T 与先验相同或差 0.014（Cricket 1.000 → 0.986，同一噪声带）。
3. **可以写的（限域变体预注册复验后）**：E_T T-CLSC 在信任域内给出的零样本名单 + SH6-3-3 六靶均值 0.564 vs 先验 0.542，以 SH6 的成本接近 SH10-4-3 的 0.567；
   **不能写的**：预注册口径下 E_T 名单优于先验（FLAT）；比较器可以在目录外提名（再次否定）。
4. 工程项：E_T 在官方全长序列上出界（|z| 到 15），需要在部署路径里裁到 ±4（A″ 的护栏）；比较器排名只在信任域内做。
