## 0. 动机（为什么做，不是为了让谁过闸）

两版闸门判据（旧 SNR+符号稳定、gate v2 δ 后产量+方向正确率）都被**探针 CLS 集合的
构成**支配：剂量-反应 Pearson(退化 CLS 占比, 任务数闸) = 0.751 / 0.719，闸门过不过
由"探针集里塞了几条退化 CLS"决定，而非数据集质量。

循环性的根源在**选取方式**：当前 10 条探针按 HAR 排名刻意跨好坏挑选，为覆盖"差"的
一端必然纳入退化 CLS，而退化 CLS 主导闸门结果。改为**从 `configs/space.yaml` 均匀
随机采样**（空间 4.73×10¹² 个合法配置），消除"人为挑选"这个自由度——随机样本代表
真实 CLS 空间的自然分布，而非人为构造的好坏光谱。这是消除循环性的正确做法，不是
换个采样方式碰运气。

## 1. 可证伪预测（实验前写死，不得事后修改）

原文（gate v2 REPORT §5.7 提出、用户指令原样引用）：

> **在随机常规 CLS 下，AWR/CT/ERing/NATOPS 四个中只有 NATOPS 会过。**

操作化（全部写死）：

- **"过"** = gate v2 判据原样：`∃δ∈grid: A(δ)≥0.95 ∧ Y(δ)≥1/3`。A_FLOOR=0.95、
  Y_FLOOR=1/3、DELTA_GRID=0.005…0.200、canonical=seed 0、consensus=seed 1/2/3
  ——`scripts/gate_v2_eval.py` 的 `pair_observations` + `gate_v2_decide` **逐字复用**，
  一个数都不动。
- **"随机常规 CLS"** = 20 条随机样本中剔除按 §3 标准标注为**退化**的条目后的常规
  子集（**R-reg 口径**，候选对 = 2 任务 × C(n_reg, 2)）。这是预测的**主判定口径**。
- **预测判"中" ⟺** R-reg 口径下 NATOPS pass **且** AWR、CharacterTrajectories、
  ERing 全 fail。任何其他组合 = 预测错（部分或全部），如实报告并分析。
- **R-full 口径**（20 条全上，含退化标注条目）同时报告——它是"阶段2 生产随机采样
  实际会看到什么"的对照，**不参与预测判定**。
- **NATOPS 阳性对照**：它在 gate v2 下 pass 且剔退化 CLS 后仍 pass（27 条 label、
  0.962）。若 R-reg 下 NATOPS 不过 → **实验设计本身存疑**，主结论判"设计失败"并
  分析原因（如随机常规 CLS 的 R' spread 不足以产生过 δ 的配对）；此时不得把其余三个
  的 fail 当作预测部分应验来报告，但仍如实给出"若按表面值读，源池只剩
  Handwriting/NATOPS/UWave 三档结论如何变化"的附注。

## 2. 采样方案（已执行，目录与本文档同 commit）

- **数量 n=20**，理由：
  1. 与阶段2 每任务 CLS 预算同规模（10 shared + 10 random = 20），Y 的绝对值首次
     具有生产口径含义；
  2. 候选对 2×C(20,2)=380/数据集，是 gate v2 的 90 对的 4.2 倍——A 的判定粒度从
     "n_kept=30 时 ≥0.95 实际要求 29/30"（gate v2 limitation 2）改善到 δ* 处可容
     约 5–6 个错误配对；
  3. 成本实测可控（§6，总 GPU <1.5 h）；
  4. 逐个接受制前缀稳定，将来加大 n 不作废缓存（铁律 3）。
- **方法**：`autocls.labeling._sample_unique(space, np.random.default_rng(20260804), 20, set())`
  ——逐个 `space.sample_random` + `cls_key` 去重，与阶段2 生产随机采样同一循环语义。
  **不看任何性能信息、不按好坏覆盖挑选、不与旧探针目录去重**。种子 20260804（日期），
  与 n 一起是采样仅有的两个自由度，均在此写死。
- 生成脚本 `scripts/sample_random_cls_catalog.py` + 单测 `tests/test_decouple_sampling.py`
  （确定性/前缀稳定/合法性/条目不携带性能字段/钉死已提交目录五条性质）。
- **退化 CLS：采完后标注、不剔除**。独立理由（与结果无关）：
  1. 估计对象是空间的**自然分布**——在采样端加剔除规则等于重新引入"人为挑选"这个
     正在被检验的自由度；
  2. 阶段2 生产随机采样（`sample_random_cls`）同分布，闸门应测生产实际会看到的东西
     （这正是 gate v2 修口径不一致时的原则）；
  3. 随机样本中的退化占比本身是研究产出：它回答"CLS 空间里有多大比例是'训不动'的
     配置"（§5.5）；
  4. 标注（而非剔除）同时支撑 R-full / R-reg 两个口径与剂量-反应重算（§5.3）。

## 3. 退化 CLS 客观识别标准（基于训练行为，不基于配置）

**定义：退化 ⟺ 预训练不产生统计可检出的正向训练效应。**

- 对每条 (dataset, task, seed) 运行**配对基线**：同 `weight_seed`/`split_seed`、
  `iters=0`（`pretrain_encoder` 零步，encoder 停在随机初始化）跑同一下游评估 →
  R'_base。`evaluate_rprime` 在 `build_encoder` **之前** `torch.manual_seed(weight_seed)`，
  基线与正式跑的初始权重逐位相同、eval 划分逐字相同 → **严格配对**，差值只含
  训练效应（+ GPU 非确定性小噪声）。
- 训练效应 `d_i = R'_c(t,s) − R'_base(t,s)`，全池 4 数据集 × 2 任务 × 4 种子 =
  **32 个配对格**（只取双方有限的格）。
- **判退化 ⟺ 单侧配对 t 检验在 α=0.05 下不能拒绝 H0: mean(d) ≤ 0。**
  （Wilcoxon 符号秩同报作稳健性诊断，不参与判定。）
- 有限格 <24/32 → 状态 `unknown`，不入任何一类、单独报告（预期不发生：阶段1 补跑
  1040 条零 NaN 零 OOM）。
- **为什么不用配置规则**：CRITERION.md §3.1 已证配置界线划不清（`8c4aa283` 同样
  τ=0.01 却是 HAR 第 3 名）。**为什么不用组内 |z|**：z 从被评估的同批样本内部取，
  正是要消除的循环——基线对照是**绝对**判据，不依赖样本里其他 CLS 的构成。
- 语义说明：本定义把"训了但训坏（不如随机初始化）"也归入退化——机制上它们同样以
  远低于群体的 R' 制造平凡配对，正是剂量-反应要计量的对象。

## 5. 预注册分析清单（跑完只填数，不加不减；超出此清单的分析须标注"探索性"）

1. **每数据集 gate v2 判定**：R-reg 主口径 + R-full 对照，各给 verdict/δ*/Y/A/n_kept。
2. **与预测对比**：按 §1 规则逐字判中/错。
3. **循环性检验（剂量-反应重算）**：从 20 条中抽 k=10 子集（固定
   `default_rng(20260804)` 抽 2000 个；C(20,10)=184756 全枚举不必要），逐子集重放
   gate v2，算 Pearson(子集退化占比, 响应)。**响应 = Σ planned_tasks(过闸者)**：
   AWR 8 / CT 16 / ERing 6 / NATOPS 10，满分 40。
   - **对照基线（旧数据，本文档写定）：0.744** = 旧探针 10 条、637 个子集、同 4 个
     数据集、同响应定义下的 Pearson（退化=数据驱动 |z|>2 口径：n_tail=0 均值 11.2 /
     n_tail=2 均值 40.0）。§3.1 验证给出旧 10 条在**新标准**下的退化标注后，再用新
     标注重算一次该基线（先于 GPU 实验 commit 进 VALIDATION.md），作为最终对照数。
   - **判读规则（写死）**：新实验 Pearson 显著低于对照 → 循环性主要来自人为挑选；
     仍在同量级 → 退化 CLS 的影响是 CLS 空间固有属性、不是挑选造成——另一个同样
     重要的结论，如实报告。
   - 若随机样本退化条数 <2：剂量-反应统计不可估——这**本身就是结论**（自然分布中
     退化 CLS 稀少到不构成支配因素），如实报告，不硬造相关数。
4. **注册表 δ 兑现核对**：AWR 0.08 / CT 0.05 / ERing 0.06 / NATOPS 0.06 下的实测
   A 与 Y，对照 δ*（gate v2 §3.1 已知 7/13 兑现不了 95%，这里给随机 CLS 下的版本）。
5. **退化占比**：20 条中判退化条数 + Wilson 90% 区间——"CLS 空间里多大比例配置
   训不动"的首个测量。
6. **诊断（不参与判定）**：随机 CLS 的 R̄ spread 与旧探针 10 条对比（解释产量差异）；
   任务级留出 δ*（gate v2 §5.4 同款）；平凡 label 占比（尾部=本实验标注的退化条目）。

## 6. 成本（5090 实测外推，阶段1 缓存 seconds 字段）

单条 R'（290 iters）：AWR 13.1 s / CT 20.3 s / ERing 11.7 s / NATOPS 13.1 s（均值）。
640 条 ≈ 2.6 h 串行 → 8-worker 单卡 wall ≈ 25–40 min；基线 640 条无预训练（估
≤5 s/条）≈ 附加 10–15 min。**总 GPU 时间 <1.5 h（含开销），单卡 5090 即可，
无需 4 卡。**
