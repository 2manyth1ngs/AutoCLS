本实验之前没算过任何子集先验。已知的相关读数：7 折 LODO 全量（各折 7 个训练源）先验@1 regret 0.046、prior3、SH6-3-3 @290 0.018（`mx4_prior_sh`）；

## 1. 设计
- 折 = 7 个靶（SCP2 只训练不作折，与 36 号同）。每折训练源 = 其余 7 个数据集（含 SCP2）。
- k = 1..7：枚举全部 C(7,k) 个子集（7/21/35/35/21/7/1），子集先验 = 子集内 shared-10 行的 within-(切片, 预算) z 均值（`36.prior_scores` 同式）。
- 靶上每个实例（切片 × 预算，20 条候选 = shared-10 + random-10，与 36 号同）算：regret@1、regret@3、oracle 是否在先验前 6、@290 的 SH6-3-3 regret（先验前 6 → 3 → 3，同一轨迹截点）。
- 汇总：先在折内对子集取均值，再对 7 折取均值；另报子集间 sd（收敛 = sd 收缩）、子集 top-1 与全量（k=7）top-1 相同的比例、子集先验与全量先验在 shared-10 上的 Spearman。
- 代理（GBDT）不进本实验：它的 top-1 从未超过先验，且本问题问的是先验。

## 2. 判读带（先写死）
- **收敛**：k=4 与 k=7 的 regret@3 @290 差 < 0.005 且 SH6-3-3 @290 差 < 0.005（都在单跑噪声 0.035–0.048 之内），且 k≥4 时 top-1 相同比例 ≥ 0.8。
- **未收敛**：k=7 比 k=4 好 ≥ 0.01（regret@3 或 SH），或 top-1 相同比例在 k=6 仍 < 0.8。
- 中间情况按数字如实报。
