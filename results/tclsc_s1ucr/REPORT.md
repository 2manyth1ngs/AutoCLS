## 4. 读法

1. **n 放大证实了机制、没兑现价值。** 指纹臂从反向（−0.042）到正向（+0.018）是"7 个点过拟合"最直接的证据；φ 臂的 zero 消融从不显著到显著、
   regret@3 从 +0.002（更差）到 −0.001（更好，p 0.045）。方向全对，量级全小：好半区 Δ_M1 0.02 量级，regret 增益 0.001 量级。
2. **可迁移的预测式信号到 n=72 仍止于粗排序 + 极小的选择增益。** 对照的量级：直接实测 6 条探针的 regret@3 0.0125 = 任务盲的 58%，
   而学到的 φ 映射只给 5%。这和 WP12 的结构（好半区高秩、数据集特异）在 12× 的 n 下没有翻转——不是样本不够，是**低维任务描述量对好半区偏好的信息量本身小**。
3. **指纹在 all20 视图里的大增益（regret@3 0.017 vs 0.022）是比较器学会了"相信实测"**：探针的 @60 实测在指纹里，它把这些候选排到前面。这是
   合法的部署价值（等价于 SH 第一级），但不是外推；nonprobe 视图把它剥掉后剩 0。
4. **头的结论第三次稳住**：concat 在 UCR 84 上仍零。
5. **对主臂的含义**：预测式 dataset-aware 在比较器形态下能成立的部分 = (i) 粗排序（破坏性 vs 可用，φ 可迁移、跨 n 复现）；(ii) 极小的选择增益（n=84 才显著）。
   要拿到好半区的选择价值，剩下的可迁移变量只有真 E（表示空间，维度高）；但按 φ / 指纹两轮 + WP12，先验上它也会落在同一结构里。
   更诚实的写法是把 SH 的实测当主臂的"测量式实现"，把预测式的边界（粗排序可迁移、好半区不可迁移、n 曲线）写成 analysis 章的核心图。
