# 行为条件化侦察 REPORT：测量条件化（转导补全）选拔场判负——过闸失败，家族在本口径下关闭

**一句话结论**：用目标自己的 j 个实测格子做行为条件化，**数据集级读得出"整体水平"
但读不出 per-CLS 结构**（svd 臂稳定胜任务盲列先验 p=0.006–0.040，却全程胜不了只调水平
的平移臂 p=0.51–0.98）；**任务级 3 锚插值被全局先验碾压**（"测量优先于预测"第四次出现）。
D1r / D2r 双双不过，闸门 **fail**。测量条件化家族在 @290 + 共享 10 CLS + k=1 口径下判负；
是否立 norevive 条款交用户。

## §6 含义（给管线的三条）

1. **看门层现行设计再获正面证据**：金丝雀直测 + 全局先验恰好就是"平移臂"的语义——
   本侦察证明它已吃尽 j 格测量的可提取信息，**现行看门层在 k=1 口径下接近信息论最优**。
2. **任务级条件化的最后一条零 GPU 路走完**：固有特征（宽面板 D1w）与行为测量（本侦察
   D2r）两类条件化输入都输给更笨的基线。剩余唯一未排除的假设 = **k=1 标签信度天花板
   （κ≈0.47）压制了一切格级结构**——C 升级路径（UWave+HW 补 4 seed ≈640 格 @5090 3.5h，
   协议 §7）是唯一能分离"结构不存在"与"信度不够"的实验，但第 0 步未触杀档，协议不
   自动触发，是否投入交用户。
3. svd-vs-列先验的稳定显著（四口径 p≤0.04）可安全引用为"**自测格子能估数据集毒性水平**"
   的又一佐证（与金丝雀结论同向），不构成条件化证据。
