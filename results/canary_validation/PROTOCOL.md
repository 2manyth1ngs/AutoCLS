# 金丝雀探针有效性协议：看门层直测方案的预部署验证（判读带先于计算写死）

日期：2026-08-30 ｜ 脚本：`scripts/20_canary_validation.py`（零 GPU，320 格
面板模拟）｜ 单测：`tests/test_canary_validation.py` ｜ 决策树（用户
2026-08-30 拍板）：**有效 → 看门层定案（金丝雀直测），任务级条件化搁置；
无效 → 进任务级条件化预检**。

## §1 问题

B 路线看门层 = 对未见数据集花 j 条测量（iters=0 基线 + 哨兵 CLS @290）
直接估计毒性。本协议在 320 格面板上模拟该部署协议，回答：**这么少的测量
够不够用**——估计值能否追踪真实毒性排序、能否把危险数据集分对档。
全程 task-blind（哨兵选择/校准只用训练折全局统计，无 E/TS2Vec 参与）。

## §2 偷看披露

已见：全部 320 格 label、MX-1c 的 raw/shrink_g 误差数字（j=3 raw 中位
0.196 / 全局收缩 0.119）。哨兵设计与校准估计器未算过。

## §3 设计（先于计算写死）

真值：数据集破坏率 p_d（20 格）。16 折 LOO：哨兵排名与校准只用该折
15 个训练数据集的 300 格。

**主设计 sent_cal（部署方案候选）**：
- 哨兵 = 训练折 per-CLS 全局破坏率降序前 j 条（"毒哨"——全局最毒的 CLS
  是毒性最有信息量的金丝雀）；cell 指派 = 轮转到 2 个任务（cls1→_00、
  cls2→_01、cls3→_00，确定性）。
- 估计 = 线性校准：15 个训练数据集各自算同款哨兵破坏比例 s 与真值 p，
  最小二乘拟合 p≈a+b·s，套用到留出数据集的 s，截断 [0,1]。
  （偏差校正的由来：毒哨是有偏样本，原始比例高估毒性。）
- 每折确定性单值（无抽样随机）。

**对照 shrink_rand（无设计基线，MX-1c 在位估计器）**：j 随机格 +
全局先验收缩（m=4），R=500 次抽样（种子派生写死），逐 draw 评估
（部署只有一次抽样，禁用 draws 均值粉饰）。

预算 j ∈ {2,3,5}；**主判读点 j=3**（写死）。

## §4 判读带（先于计算写死）

主设计 sent_cal @j=3 过双门 = **有效**：
- **V1（排序门）**：Spearman(估计, 真值) 跨 16 个 LOO 数据集 ≥ 0.5 且
  p<0.05。
- **V2（分档门）**：真值危险档 = p_d ≥ 0.40（面板内 5 个：NATOPS/Ethanol/
  SCP2/AWR/Cricket）；判定规则 = 估计 ≥ 0.30 报危险（阈写死）；
  balanced accuracy（TPR/TNR 均值）≥ 0.75。

| 条件 | 判定 |
|---|---|
| V1 ∧ V2 | **有效**：看门层定案（哨兵 j=3 + 线性校准 + iters=0 基线），任务级条件化按决策树搁置 |
| 恰一门过 | 边缘：交拍板（j=5 敏感性佐证方向） |
| 双门不过 | **无效**：按决策树进任务级条件化预检 |

## §5 稳健性与诊断（预注册，不改判读带）

- R1 单种子现实性：13 个 k3 数据集的哨兵 cell 改用单种子 R'（噪声缓存逐
  种子行，3 种子各算一遍 flag）重算 V1/V2——部署时金丝雀是 k=1，主判用
  k3 均值 flag 是乐观上界，此臂给现实下界。
- 诊断：sent_cal vs shrink_rand（设计有没有用）；j∈{2,5} 敏感性；
  逐数据集估计-真值表。
