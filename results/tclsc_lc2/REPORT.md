问题：步骤 2（S⁺ 上每切片补 20 条新标签 ≈ $12）的零新 R' 判死门——训练侧每切片的好区域随机配置数从 0 → 3 → 5.6 → 6.2 → 16.2（+ NB1 邻居）增加，比较器对 held-out 数据集上**从未见过的配置**的排序是否变好？

## 0. 一句话结论

**读数码 LC2-FLAT**（G-L1 ✗、G-L2 ✗、G-L3 ✗；预测 P2 命中，**1/5**）。
曲线是 **U 形回到起点**：只用 shared-10（k3）训的比较器对未见配置的非坏区配对准确率最高（E_T 0.682 / 任务盲 0.664）；加入 3 条 k1 随机配置标签后**下降**（0.636 / 0.553，R0→R3 −0.047 / −0.111，p ≈ 1）；再加到 6.2 条几乎不动（0.641 / 0.569）；加上 NB1 邻居到 16.2 条才回升（0.676 / 0.646，RA→RN +0.035 p 0.002 / +0.076 p 2e-5），仍不超过 R0。
E_T 比任务盲**抗标签噪声**（每点 E_T − 盲 +0.03 ~ +0.08，p ≤ 0.001；R0 +0.018 p 0.058），且在 RN 点校准最好（预测前 3 的未见占比 − 真占比 −0.001，任务盲 +0.27）——但 EV1 已证明同样的 NB1 训练集（= RN）在搜索压力下仍高估 +0.81。
**读法：好区域的 k1 标签数量不是杠杆——k1 标签先把排序拉低、再用 16 条才补回来；步骤 2 的 +20 条 S⁺ 标签最多把曲线抬回 R0 附近，全空间路线在标签侧关闭。**

## 1. 设计要点

- 标签池：shared-10 k3（K3）+ random-10 k1（mx3 / SX，SP1 过滤 ẑ ≥ τ 后 540/870 = 62%，每切片均值 6.2 条）+ NB1 邻居 k1（固定 4 视为已见、切片 6 未见）。曲线点 R0 / R3 / R6 / RA / RN = 每切片非 shared 0 / 3 / 5.6 / 6.2 / 16.2 条（嵌套、切片派生固定种子、三截点同进同出）。
- 臂：`ft60_hard`（E_T field）/ `blind_diff_hard`；73 号训练原样（δ_k1、ctx 折内标准化）；LODO 7 折 × seeds 0/1/2 多数票。
- 考卷固定：每 held-out 数据集 12 切片 × 3 截点 = 252 实例 / 臂 / 点；30 条 = shared 10 + 固定邻居 4（已见）+ random 10 + 切片邻居 6（未见，k1 真值）。
- 指标：未见配置间 |Δ| ≥ δ 的配对判对率（全部 / 非坏区 z ≥ −1）、未见 regret@3、over（预测前 3 未见占比 − 真占比）、above_trust（预测排在最好 shared 之前的未见数 vs 真）。

|---|---:|---:|---:|---:|---:|---|
| R0（0，只 shared k3） | **0.682** | **0.664** | +0.018（0.058） | **0.020** | −0.31 | 0.11 / 0.91 |
| R3（3） | 0.636 | 0.553 | +0.082（<1e-3） | 0.033 | −0.07 | 1.03 / 0.91 |
| R6（5.6） | 0.637 | 0.583 | +0.054（<1e-3） | 0.037 | −0.08 | 0.95 / 0.91 |
| RA（6.2） | 0.641 | 0.569 | +0.072（<1e-3） | 0.036 | −0.07 | 0.91 / 0.91 |

台阶（同实例配对，H1 = 后点更高）：R0→R3 E_T −0.047（p 0.998，71:107）/ 盲 −0.111；R3→RA E_T +0.005（p 0.08）/ 盲 +0.016（p 0.012）；**RA→RN E_T +0.035（p 0.002，109:71）/ 盲 +0.076（p 2e-5）**；R3→RN +0.040 / +0.092。
任务盲的 over：R0 −0.43 → R3 +0.22 → RN +0.27（随机标签把任务盲教成"未见配置往前排"）；E_T 一路在 −0.31 → −0.07 → −0.00。

## 4. 读法

1. **k1 随机标签先伤后补**：3 条 k1 好区域标签让未见配置排序从 0.68 掉到 0.64（任务盲掉 0.11）——它们教会比较器"未见配置不是垃圾"（over 从 −0.31 抬到 0），却因 k1 噪声（好区域真差 ≈ 0.02 = 噪声）搅乱了细排序；要到 16 条（含 NB1 邻居）才回到起点。步骤 2 的 20 条 S⁺ 标签按此曲线外推最多抬回 R0 附近，与 R0 的差在 ±0.01 内——$12 买不到东西。
2. **标签质量 > 数量**：R0 用的是 k3 的 shared 标签，未见配置排序反而最好；把 k1 标签换成 k3 要 3 倍成本（≈ $36），且 K3 检验已示训练标签 k1→k3 对排序的增益只 −0.001。
3. **E_T 的真实价值 = 抗噪 + 校准**：每个点 E_T 都显著优于任务盲（+0.03 ~ +0.08），RN 点 over ≈ 0 而任务盲 +0.27。但 EV1 用的就是 RN 同款训练集，进化一搜仍把 E_T 推到 +0.81 高估——**固定考卷上的校准不等于搜索压力下的可靠**。
4. **对四步计划**：步骤 2 不做。AutoCTS++ 式"全空间 − 剪枝 + 均匀标签 + 比较器搜索"在本语料的三个前提（任务数、标签噪声、空间可用率）里，标签噪声这一条把"加标签"的路堵死了。
5. **对论文**：E_T 的抗标签噪声性与校准（LC2）、避坏能力（EV1）、信任域内选择增益（K3）可写进 analysis；"E 引导的开放空间搜索"不能写。

## 4b. 补充点 R0k1：下跌是噪声还是分布？（协议 §7，判读先于数据）

只 shared-10、标签换成 k1（seed-0 单值）：E_T **0.672** vs R0（k3）0.682（−0.010，p 0.17，91:68）、任务盲 0.662 vs 0.664（−0.002）。预注册阈值 −0.03 未到——**k1 噪声只解释 R0→R3 下跌（−0.047）的五分之一**；R0k1 → R3 仍 −0.036（盲 −0.108）。
读法：加入随机配置标签造成的损失来自这些标签的**分布**（它们把比较器往"未见配置往前排"的方向拉、并用 field 级弱信号覆盖了 shared 学到的细排序），不是每条标签的噪声；把 540 条 S⁺ 随机配置补成 k3（≈ $10）预期收回的只有 ~0.01，不做。K3 检验的同一结论（训练标签 k1→k3 −0.001）在未见配置口径上复现。

## 5. 诚实项

- 曲线点的随机子集按切片派生固定种子；换种子未跑（LC 检验经验：切片 / 配置轴方向稳）。
- 真值 k1；非坏区按考卷 30 条内的 z ≥ −1 定义；未见配置对每个模型确实未见（随机配置按切片派生、held-out 数据集从未参训；固定邻居 4 因跨切片同 key 归入已见）。
- HMD / Ethanol 两折的标签本身接近噪声（SP1），逐折读数在这两集上不可解释。
