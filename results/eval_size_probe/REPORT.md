## 2. 闸失守诊断（判定：环境噪声，非实现差异）

- 14 个失配全部为 **1–4 个 eval 样本**（0.008=1/125 档 8 个；0.013–0.026=2–4/155
  档 6 个）、方向双向、集中在 SWA 探针 §2 点名的同一批上下文敏感 CLS
  （20be4f74/8b87d66f/a1f67db4/9092e36e）。
- **决定性诊断**：最重失配 cell（HW_00/20be4f74/rep2，Δ=4 样本）新鲜进程同码
  同种子复算 3 次 → **3 个互不相同的值**（0.3871/0.3935/0.4323，散 0.045）。
  与 SWA 时代"新鲜进程 3/3 逐位复现"不同：**今天这台机器在新鲜进程层面就不
  确定**。nvidia-smi 显示 GPU 被桌面持续负载分时（动态壁纸等），运行时算法
  选择随并发状态漂移。
- **实现等价的证据**：46/60 cell 逐位相同——eval_cell 若与 evaluate_rprime 有
  任何系统性差异（切分/池化/SVM 不同），60 条会全部偏移而非整样本双向散布。
- **对结论的影响评估**：β 是同一环境内的相对量（60 cell 同进程同状态），机器
  噪声与种子噪声同为"翻转 eval 样本"，混入 ε 不改缩放指数；水平锚全部对上
  （f=1 档：HW_00 P95=0.1097 与发布逐位同、med 0.026/0.036 vs 发布 0.029、
  P95 pooled ≈0.107 vs 0.110）；UM 外推（0.91）完全不依赖逐位锚。

## 5. 若拍板采纳 CONFIRMED，推论与行动面（协议 §6）

1. **n_eval 是 label 噪声的一阶决定量（中位体）**：δ 预算可按 n_eval 反推
   （0.055 档 ≈540、0.033 档 ≈1500，均 β=0.5 外推）。
2. **δ 的 P95 口径不跟随**（β_p95=0.27）：扩评估侧要落到 δ，必须配两制式协议
   （退化判据 v2 隔离破坏性 CLS 后在非破坏制式上标 δ）——与已关闭的 per-CLS δ
   不同（那是逐 CLS 估噪声，这是按制式分流）。
3. **切片器 `n_samples=1024` 上限是可解的瓶颈**：UM 恰撞线（eligible 数千），
   评估侧单边扩容（n_train 与 iters 工作点不动、其余 eligible 划给 eval）可把
   UM 的 n_eval 307→~2000，等价 k≈6.5 的平均而 GPU 成本 ≈k=1。HW（全集 1000）
   无余量——有信号的骨干救不了自己，兑现须作为下一轮入池判据
   （headroom **且** eligible≥~5000/任务）。

## 6. Limitations

1. 单数据集（HW）2 任务；跨数据集普适性靠 P4 外推（单点 0.91）支撑。
2. 有效性闸 FAIL：本轮所有绝对量（med/P95/q）含 ≤0.045 的机器噪声分量（对最
   敏感 CLS）；相对量（β、外推比）稳健但正式判定待拍板。
3. bootstrap CI 宽（10 CLS 可交换单元太少）；点估与 per-task 一致性是主要支撑。
4. 子集是同一 eval 集的嵌套重采样（counterfactual 语义），非真正独立小评估集；
   有限总体相关性对 med 的影响二阶。
5. q=0.171 为判对不一致率（含双错不同类不可见），是预测不一致率的下界。
