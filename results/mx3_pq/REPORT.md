# MX-3-PQ 报告：AutoCTS++ 同构的多源池 zero-shot 实验（对比学习版）

协议锁：`PROTOCOL.md`（数据前写死）。执行：RunPod pod `hlp3nsvl4fpg5o`（RTX 5090 32 GB，EU-RO-1），
2026-09-02 18:46 开机 → 2026-09-03 05:43 UTC 停机（§6）。代码：分支 `mx3pq`，R' 阶段 `7608750`，补格与后半程 `191b395`。
本文所有 R' / 增益 / δ 均为 **@iters ∈ {60, 120, 290}、bs=128** 口径（铁律 2）。

## 0. 一句话结论

在 7 折 leave-one-dataset-out × 3 预算的 AutoCTS++ 同构协议下，**通用 CLS 排序器成立**（D1 p=2.4e−15，top-3 regret 0.038，
成本比目录直搜低 5×、比 full-iters 直搜低 1.6–2.3 个数量级），但**任务嵌入 E 与预算描述符 b 都没有贡献**：判读码 **B-DEAD**
（budget 消融 7/7 折零、E 换位 0/7 pass、A0 与任务盲先验持平、D2 不过、进化搜索 D3 不过）。根因在配对标签本身——
跨预算翻转 ≤ 2.5%、任务盲天花板 0.97–0.99——数据集级 task-aware 在本栈按预注册协议判负，与切片级判死叠加。

## 5. 判读与预测对账

### 5.1 判读码：**B-DEAD**（`analysis.json: verdict`）

| 条件 | 结果 |
|---|---|
| E-ALIVE：A0 cross ≥5/7 pass ∧ pooled p<0.05 ∧ Q3 A0>A6 | ✗（cross pass 0/7；pooled p=0.29；Q3 Δ=−0.006 p=0.47） |
| E-DETECT：A0 cross ≥4/7 detectable | ✗（2/7） |
| LABEL-BLIND：A0 cross 零 ∧ A8 cross 零 | A8 cross 零成立，但 A0 cross 只有 3/7 零（另 2 detectable + 2 ambiguous），未同时满足 |
| E-PATHWAY：A0 cross 零 ∧ A8 cross pass | ✗（A8 零） |
| **B-DEAD：A0 budget ≥5/7 折零** | **✓ 7/7** |

协议对 B-DEAD 的要求是"先查实现"。实现侧：ctx 通路接通（zero_ctx 使 1/2978 对翻转，`tclsc_model` 的 ctx 单测与冒烟链均过）。
**标签侧（零 GPU，终版缓存 2835 行）才是根因**：

| 量 | @60 | @120 | @290 |
|---|---:|---:|---:|
| δ 存活率（单向对 / 8550） | 0.402 | 0.315 | 0.415 |
| 任务盲天花板（跨任务多数票一致率） | 0.974 | 0.986 | 0.981 |
| 两预算都存活的配对里标签翻转率 | (60,120) 0.85% · (60,290) 2.5% · (120,290) 0.44% | | |

预算轴上，同一对 CLS 的优劣在 97–99.5% 的情况下不随 b 改变；数据集轴上，各数据集标签偏离全池多数票的比例 ≤ 8%
（例外：HMD@60/120 17–19%、SCP2@290 31%，SCP2 不作 LOO 折）。**训练信号里几乎不存在需要 E 或 b 才能解释的配对**，
模型学不到用它们不是通路坏了，是标签不需要。这把 M3/C2/实验 1-2 在切片级得到的"task-aware 判死"扩展到了
**数据集级 + 预算级、7 折 leave-one-dataset-out** 口径。

### 5.2 A1 / A7 的 cross pass 为什么不是 E-ALIVE

A1（每数据集自 fit TS2Vec）与 A7（软 label）在 5/7 与 3/3 折上 cross 换位显著掉准确率，但两者 normal 只比任务盲高 +0.013 / +0.015
（A1−A0 p=0.15），within 全零，且 A8 显式数据集 one-hot 的 cross 为零。三条读数只与一种解释相容：这些臂把 E 用作**数据集身份 token**
——A1 各数据集嵌入空间互不对齐，换位后的 E 落在训练分布之外，输出退化；A7 的软目标按 (数据集, b) 建噪声模型，同样给了 E 一个
按数据集分组的用法。身份 token 本身不含可迁移的排序信息（A8 零），所以 normal 不涨。协议只以 A0 判读、A1 单列，正是为了不让这类
non-compliant 读数混入主张。

## 7. Limitations

- **§8 复现闸失守**（0.760 / 0.897 vs 0.90）：敏感 CLS（20be4f74 / 8b87d66f / 65627517 / cffb5503）在长序列数据集上的 R' 跨 pod 不可复现，
  幅度 ≤ 同机换种子噪声；δ 由本轮自身噪声探针标定，label 在本轮内自洽。跨批次合并 R' 缓存时必须重做噪声探针。
- **P/Q 类比的证据上限**：预算描述符只有 3 档且来自同一条轨迹的截点；标签跨预算翻转 ≤ 2.5%，本实验无法区分"模型不会用 b"与"b 无信息"之外的第三种可能
  （更细预算网格或更早截点 <60 iters 未测）。
- **A1 non-compliant**：目标数据集参与了自身 TS2Vec 训练（无 label / R'），其 cross pass 是嵌入空间不对齐的 OOD 效应，不得当作 E 有效的证据。
- **A2 / A4 / A7 只跑 3 折**（HW/UM/Cricket），P10 的绝对折数判据在协议里写错（对 3 折臂不可达），按比例读。
- **settf_windows 标定脚本低估 4×**（curriculum 阶段的 1 epoch）；结论（100 窗口）不受影响，脚本待修。
- 12 条 OOM 补格走了分块新路径（≤ 2.6 eps）；SCP2 只有 3 切片且不作折靶；短序列端（L=51）源池仍为空。
- 比较器每进程固定 ~10 GB 显存（Set-Transformer 对 45 切片 × 100 窗口的去重前向），32 GB 卡最多两路并行。
