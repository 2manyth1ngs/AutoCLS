## §3 模拟设计（先于计算写死）

模拟的部署流程（蓝图"金丝雀直测"逐字）：对未见数据集，取 **a 个锚任务
× j 条 CLS 的完整子格**全部实测 @290，另加锚任务 iters=0 基线（5 种子，
秒级）。三旋钮读数全是测量，零预测：

1. **破坏率**（→ 剪多狠）：a×j 子格中 destroy 占比；
2. **基线带**（→ δ 分辨率）：锚任务 band 均值（只依赖锚集合，不依赖 j）；
3. **锚间异质性**（→ 适用性闸门）：a×j 三态子矩阵上 T2 行内置换检验
   （scripts/21 同统计量、同零假设），**p < 0.01 触发**（α_deploy，蓝图
   逐字）；α=0.05 仅作敏感性读数，不参与任何判定。

抽样与扫描（写死）：

- 锚任务 = 从 8 个面板任务无放回均匀抽 a 个（近似"哪些切片恰好当锚"）；
  CLS = 从 shared 10 无放回均匀抽 j 条，**a 个锚共用同一组 j 条**（完整
  子矩阵，异质性检验才可定义）。随机抽格（§1 毒哨勿复活条款）。
- 扫描 a∈{2,3,4} × j∈{5,6,7,8,9,10}；每 (数据集, a, j) 抽 R=400 draw；
  子检验 n_perm=4000（部署用 10000；对触发率估计的 MC 模糊为二阶，声明）。
  种子 = `run_seed_for(f"anchor_sim:{ds}:a{a}:j{j}", f"draw{r}")` 确定性派生。
- 向量化置换检验为 `tp.perm_test` 同式重写，等价性由单测钉死（T2 逐位、
  p 在 MC 容差内）。
- 基线带旋钮误差**精确枚举**全部 C(8,a) 锚集合（28/56/70），无 MC。
- **已知乐观方向（先声明）**：自助抽样复用真值面板同一批 k=1 格——只
  模拟了"抽到哪些格"的选择误差，**不含重测种子噪声**；canary_validation
  R1（k=1 rep 间 ρ 0.21–0.50）给出折扣方向。部署实际保真度 ≤ 本模拟读数，
  报告须原样携带此上界声明。
- 适用性闸门的门控对象 = **"是否启用任务级差异 + K 大小"**（触发 → 按锚
  分别选 cls*；不触发 → 整数据集统一 cls* 并加大 K）。它**不是**任何条件化
  预测——任务级条件化按勿复活条款保持关闭，本模拟不为其翻案。

## §4 读数与工作点选择规则（先于计算写死）

- **(a) 旋钮保真曲线**：逐 (a, j) 破坏率 MAE（每数据集 400 draw 的
  |估计−真值| 均值，pooled = 5 数据集均值）与逐数据集 bias；基线带 =
  逐 a 的 |锚均值−8任务均值|/真值 的中位与 p90（描述性，j 无关）。
- **(b) 闸门操作特性**：逐 (a, j) 每数据集触发率 P(p_sub<0.01)；
  **TPR** = 真值过闸数据集（UM、UWave）触发率均值；**FPR** = 真值不过闸
  数据集（CT、PS、HW）触发率均值；逐数据集触发率原样附表（CT 单列）。
- **(c) 工作点选择规则（写死，唯一判定）**：
  - 可行集 = {(a, j)：TPR ≥ 0.80 ∧ FPR ≤ 0.15 ∧ pooled 破坏率 MAE ≤ 0.10}。
  - **推荐 (a\*, j\*) = 可行集中 a×j（@290 格数=成本大头）最小者；并列取
    a 小者**。基线带读数为描述性，不参与可行性。
  - 可行集空 → **无推荐**：如实报 Pareto 前沿，琥珀点保持打开；可能出路
    （更多锚 / α_deploy 重定标 / 扩 CLS 目录）留给后续协议，本模拟不决定。
