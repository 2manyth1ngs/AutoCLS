## §1 量法

- Δ 的口径：@100%（iters 200 官方）acc，seed 0；官方噪声 σ_d = 该靶 3 种子冠军 acc 的 sd（uea30 / mx4_mask finals），阈值 2σ_d；缺则用中位 σ。
- **Q1 input_mask**：Δ_mask(d, c) = 孪生开 − 关，29 靶 × 11 配置（shared-10 + GGS）。报：逐靶均值 / 正占比 / 超阈占比；ICC(1)（靶为组、11 配置为评分者；置换 p：打乱靶标签 2000 次）；三种规则的名单最好值：always-off / always-on / 按靶符号（oracle 规则）/ 逐 (靶, 配置) oracle；对 SH10-4-3 冠军（3 种子均值）的差。
- **Q2 单增强开 / 关（部署口径）**：H2 六开关（23 靶）、WP15 四增强开关（52 集 × 两基）：逐字段均值 Δ / 正占比 / 超阈占比；WP15 跨基 ICC(1)（两基为评分者）；"最佳单开关 oracle − 基"的逐靶净空及超阈占比。
- **Q3 新增强字段**（WP8-AUG）：逐字段 21 配置为评分者的 ICC(1)（6 靶）、均值 Δ、逐靶 oracle 净空。
- **Q4 档位（切片口径）**：SP1 标签池（87 切片 × 21 配置 @290，z）+ NB1 邻居；每数据集拟合 HGB（bagging 5），对 8 个增强比例字段算部分依赖 PD_d(level)：(a) "开 / 关"分量 = PD(0) − mean PD(>0)；(b) "哪档"分量 = PD(>0) 的极差；(c) 跨数据集档位排序一致性 = 各集 PD(>0) 曲线两两 Spearman 均值；零参照 = 打乱数据集内标签 200 次的 (b) 分布（P95）。
- **Q5 聚合**：29 靶上"增强层 oracle"（基础 11 × 掩码）− 基础 11 最好；与 SH10-4-3 冠军差；超阈靶占比。

## §2 判读（先于数据）

| 判定 | 定义 |
|---|---|
| **D1 掩码是数据集级杠杆** | ICC(1) ≥ 0.30（p ≤ 0.05）且"按靶符号"规则名单 − always-off ≥ +0.01（均值）且 ≥ 1/3 靶超阈 |
| **D2 单增强开关在部署口径有数据集级净空** | ≥ 1 个字段：WP15 跨基 ICC ≥ 0.30 且 H2 或 WP15 上逐靶 oracle 净空超阈占比 ≥ 1/3 |
| **D3 档位携带数据集级信息** | ≥ 半数增强字段：≥ 半数数据集的"哪档"极差 > 置换 P95，且跨集档位排序一致性 < 0.5 |

**读数码**：D3 ✓ ∧ (D1 ∨ D2) → **AA-LEVEL-GO**（三档增强空间值得设，写协议算部署口径标签预算）；D3 ✗ ∧ (D1 ∨ D2) → **AA-SWITCH-ONLY**（增强只以开 / 关进空间，档位取基值）；其余 → **AA-DEAD**（增强层在部署口径没有可赢的数据集级东西，新空间要换对象）。
