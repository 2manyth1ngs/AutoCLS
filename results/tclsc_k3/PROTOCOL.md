## §1 标签（源侧新 R'，铁律 3 缓存 + --resume）

- 网格：87 个切片（原 45 = 7 折数据集 × 6 + SCP2 × 3；扩展 42 = 7 × 6）× shared-10 × rep ∈ {1, 2}，权重种子 `pq.noise_seed(切片, cls_key, rep)`（与 canonical 流不相交、与 32 号噪声探针同约定），
  划分仍 canonical；一条轨迹三截点 60/120/290。已有的 16 切片 × 10 × 2 = 320 条直接复用（--resume），新跑 71 × 10 × 2 = **1420 条轨迹**。缓存 `rprime_k3.jsonl`（行格式 = 32 号 noise_probe，`seed` = rep）。
- k=3 均值标签：R'_k3(切片, 配置, 截点) = mean{seed 0（mx3_pq / tclsc_slices 主缓存）, rep 1, rep 2}；三点不齐的格**不进标签也不进考卷**（不做半套均值）。k=1 标签 = seed 0 单值（现状）。
- δ：k=1 沿用 `results/mx3_pq/delta_calibration.json`（同一数据集的扩展切片同值）；k=3 用 **δ_k3 = ⌈δ_k1 / √3⌉₀.₀₀₅**（δ 是同格重复差的 P95，均值标签的差噪声按 1/√3 缩；量子下限同比例；向上取到 0.005 步）。规则先于数据。
- 估时（SX 在同型 pod 实测每条轨迹秒数）：Ethanol 200 × 110 s ≈ 6.1 h 为长杆，其余 7 集共 ≈ 11 h；按数据集分 3 进程并行（P1 Ethanol；P2 PS + UniMiB；P3 HW + UWave + Cricket + HMD + SCP2）墙钟 ≈ 7 h，5090 ≈ **$8–10**（含 setup / 传输）。

## §2 比较器：信任域内比较器（训练与考试都只在 shared-10 上）

部署时比较器只排信任域（shared-10 + GGS），本协议把训练和考试都收到 shared-10：避免 shared 是 k=3、random 是 k=1 的混合 δ；问题也正好是用户主张的形态——**E 能不能在这 10 条里选对**。
- 臂：`ft60_hard`（E_T@60 ⊕ φ12 ⊕ b，field 头）、`blind_diff_hard`（任务盲 diff 头），训练材料 = 训练侧全部切片（12 × 6 集 + SCP2 3 = 75 切片）× shared-10 × 3 截点 的 δ 硬配对；
  两套标签 **K1**（seed 0）/ **K3**（三种子均值，δ_k3）→ 2 × 2 = 4 个模型族；7 折 LODO × 6 种子（两组 3 种子多数票、两组 pooled）。ctx 表 = ctx_uea ∪ ctx_ext（标准化只用当前训练切片）。
- 零训练参照臂 `prior`：训练侧切片上 shared-10 的 within-slice z 均值排序（源池先验），K1 / K3 各一份。
- 训练入口 = 73 号 `train_fold_uea`（rows 只含 shared 行、r_prime 已换成 k 均值、δ 表换成对应 k）；C0 = 用 K1 行训 ft60_hard Handwriting seed 0 时，若行集合 = 原 20 条则与 T 检验逐位（本协议 shared-only 无逐位参照，改为 **C0′**：K1 标签 = 主缓存 seed 0 值逐位、K3 的 16 个探针切片均值与 32 号噪声探针逐位）。

## §3 考卷

考侧 = 目标数据集全部 12 切片（原 6 + 扩展 6）× 3 截点 = 36 实例 / 靶，7 靶 × 两组种子 = **504 实例**；候选 = shared-10。
真值两套：**k3 真值（主）**、k1 真值（副表，展示考卷本身变干净的效果）。指标：regret@3（主）、regret@1、hit@3、M1 = 好半区（k3 真值前 5）内 δ 配对准确率、M0；
消融：**cross**（目标切片的 E_T 换成训练侧他集切片的，3 个错位种子）为主、zero 为辅，对 K3 与 K1 的 E_T 臂都做。

## §4 判读（先于数据；主读数在 k3 真值上）

| 门 | 定义 |
|---|---|
| C0′ | K1 标签逐位 = 主缓存；16 探针切片的 K3 均值逐位 = 32 号噪声探针 |
| **G-K1**（主） | K3 标签：E_T regret@3 < 任务盲 regret@3，配对 Wilcoxon p < 0.05 且 Δ ≤ −0.003（n = 504） |
| **G-K2** | K3 E_T：cross 消融 regret@3 > normal，p < 0.001 |
| **G-K3** | E_T：K3 标签比 K1 标签 regret@3 低，配对 p < 0.05 且 Δ ≤ −0.002（同一考卷 k3 真值） |

**读数码**：G-K1 ∧ G-K2 → **K3-E-WIN**（干净标签下 E 在信任域内选得比任务盲好，主张成立的最小形式）；¬G-K1 ∧ G-K3 → **K3-LABEL-WIN**（标签干净了、E 更好了，但仍不赢任务盲：好半区偏好主要是全局的）；
其余 → **K3-FLAT**（标签噪声不是 E 的瓶颈）。只报：任务盲臂 K3 vs K1、prior 臂、k1 真值副表、逐折、M1 / hit@3。
