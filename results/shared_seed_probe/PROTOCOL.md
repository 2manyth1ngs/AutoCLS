# 共享种子交叉探针协议（判据先于数据 commit）

日期：2026-08-28 ｜ 脚本：`scripts/9_shared_seed_probe.py` ｜ 单测：
`tests/test_shared_seed_probe.py` ｜ 本协议与代码先 commit，数据后跑。

## §1 假设与方差模型

现有设计 `weight_seed = run_seed_for(task_id, cls_key)`：每个 (task, cls) 各自
随机初始化。比较同任务上 cls_a/cls_b 时，ΔR' 同时含 CLS 效果与初始化效果：

    R'(cls, seed) = f(cls) + g(seed) + ε(cls, seed)

- 独立种子（现状）：ΔR' 噪声方差 = 2·Var(g) + 2·Var(ε)
- 共享种子（common random numbers，配对比较经典方差缩减）：g 完全抵消 → 2·Var(ε)

Var(g):Var(ε) 从未测过（既有数据种子与 CLS 非交叉，无法分解）。间接线索两头都有：
full-iters HW 60↔120（同轨迹两截点 = 一次配对比较）是全项目唯一好半区显著
（ρ=0.821）；但噪声与 CLS 破坏性强相关（预测 ρ=0.69–0.88、UniMiB 0.52）提示
相当份额是交互 ε——交互配对不抵消。本探针做完整交叉直接分解。

## §2 设计（先于数据写死）

- 数据集/工作点：**Handwriting @60 iters**（源池骨干，δ=0.110 在此标定；铁律 6 源池内）
- 任务：前 2 个（与 2c/SWA 噪声探针同口径）；CLS：10 shared 探针 CLS（目录前 10）
- 种子：**k=3 共享 weight_seed**，`shared_seed_for(task_id, rep) =
  run_seed_for(task_id, f"sharedseed:{rep}")`，rep∈{0,1,2}——**不含 cls_key**，
  同任务 10 CLS 共用同 3 个初始化（10×3 完整交叉）。split 仍 canonical
  `run_seed_for(task_id, "train_eval_split")`（生产里 split 本就任务内共享，
  故分解出的 g 恰为 weight_seed 效应）。
- 共 2×10×3 = **60 条全新 R'**（共享种子流与 canonical / "{key}:noise{rep}" 两条
  既有流不相交，零复用、零污染）；缓存 `probe_cache.jsonl` 独立文件，行含
  `shared_seed: true`，`--resume` 幂等，device_name 落盘。
- 生产脚本（2b/2c）零改动。

## §3 噪声口径（技术要点，先于数据写死）

- **独立臂**（现状噪声）：同 CLS 跨种子重复差 |R'(c,sᵢ)−R'(c,sⱼ)|，方差恰为
  2Var(g)+2Var(ε)，且就是 δ=0.110 的标定口径。n = 10×2×3 = 60。P95 取最近秩
  （2c calibrate 同式）。
- **共享臂**：单次比较噪声 ε(a,s)−ε(b,s) 不可直接观测（混信号 f(a)−f(b)），
  测配对统计量重复差 D = Δ_shared(sᵢ)−Δ_shared(sⱼ)，方差 = 4Var(ε) = 2×单次。
  n = 45×2×3 = 270。
  - **主口径**：P95_shared = P95(|D|)/√2（加性模型下方差层面精确；P95 层面对
    对称稳定形状族因子 ≥√2，故 /√2 仍偏保守或近似无偏）
  - **保守上界**：不除 √2 的 P95(|D|)
- **佐证口径**（不判定）：逐 CLS 对减跨种子均值中心后的单次偏差（ε 项两臂同等
  缩水 ×2/3、g 项只进独立臂不缩水 → 对降幅略偏乐观）；+ ANOVA 方差成分比。
- **ANOVA**：每任务 10×3 双因素 SS 分解（cls / seed / 交互+残差；单格无重复，
  交互与残差混同，如实标注）。

## §4 主判据（写死）

**降幅 = 1 − P95_shared / P95_indep**，两者均取本实验实测（分母不用历史 0.110，
防抽样漂移造假降幅；0.110 只进 §5 sanity）。

| 降幅 | 判定 | 行动 |
|---|---|---|
| **≥50%** | 绿灯 | 配对设计有实质价值（required-k → ~3 以内量级），重做 label + 重测 E 消融 |
| **20–50%** | 中档 | 看 required-k 与任务盲天花板实际值，用户拍板 |
| **<20%** | 红灯 | 噪声主体是 cls×seed 交互，配对救不了；当前结论坐实，如实报告 |

阈值理由（独立于结果）：required-k ∝ (噪声/信号)²，11→3 需噪声降到 √(3/11)≈0.52
倍 ≈ 降幅 48%，取 50%。

**跨档规则（预注册）**：√2 校正与原始保守两口径的降幅若落不同档，自动取更低档
（宁可漏判绿灯——假绿的代价是全量重做 label + E 消融，假红只是放弃一个已在
放弃边缘的选项；中档反正由用户拍板）。

## §5 有效性闸（不过则暂缓解读主判据，用户拍板）

1. 60/60 满格、零 OOM 记 NaN、零重复键（同键后行覆盖前行的 resume 追加除外，报告计数）；
2. 行级种子自检零违规（shared_seed 标记 + weight/split 逐行核对——抓"实现回退到
   含 cls_key 口径"）；
3. 每任务 3 rep 齐全的可用 CLS ≥ 8/10；
4. 独立臂 P95 ∈ [0.055, 0.22]（对 0.110 的 ±2×/½ 漂移带；n=60 误差棒本就不小，
   超带视为标定漂移）。

## §6 派生诊断（零额外 GPU，不参与判定，供中档拍板/机制解释）

1. **required-k** = (P95_shared/0.033)²（outlet_y §5 HW 容 p50 同式）；对照 11.0
   （现行）与 5.5（SWA）。校正/保守两口径都报。
2. **δ_paired** = max(P95_shared, 2×量子) 上取整 0.005（2c calibrate 同式）。
3. **任务盲天花板**两个口径：
   - 探针内真配对：逐共享种子 s 把 R'(·,s) 当该任务一份 k=1 配对测量，
     2 任务 × 45 对上按 δ_paired 过滤后算天花板（口径纯但 n 小）；
     另报配对方向跨 3 种子稳定性（|meanΔ|≥δ_paired 的对里全同号比例）。
   - labels_workpoint 反事实：HW 12 任务 k=1 独立种子 R' + δ_paired 混合口径
     （outlet_y 变体 B 近似同款局限），对照 δ=0.110 → 1.0000、δ=0 参照；
     pooled 28 任务另给 UM 按 HW 降幅同比例缩放版（假设未实测，标注仅参考）。
   对照锚：k=1 全池 0.9525、δ=0 0.7473、SWA 重标后 1.000。**此数直接预示
   E 消融是否仍零。**
4. seed 主效应 vs 交互的 SS 份额（解释降幅为何是那个数）。
