# WP16 GEO-E 检验报告：E_T 能否预测目标的损失几何家族（2026-09-18，零 GPU，1000 次置换 ≈ 15 min）

协议：`PROTOCOL.md`（协议锁 e8ef262，6 例先红 → 绿）。代码：`scripts/81_tclsc_geo.py`。产物：`analysis.json`、`tables.md`。
问题：四轮实验后空间里唯一数据集级、部署口径有净空的对象是损失几何家族（loss × sim × norm）；把 E_T（GGS 探针的响应画像，22 维 @60 / @290）当作预测器，能否在 29 个 UEA 官方靶上按靶选出家族、值出净空？这是"几何子空间分层搜索"路线的判死门。

## 0. 一句话结论

**读数码 GEO-E-DEAD**（G-G1 ✗、G-G2 ✗；预测 P4 命中，**1/4**）。
LODO 29 靶：E_T@60 选家族命中冠军家族 **0.14**（猜多数 0.38，p 0.97），选出的家族比"固定最好家族"（info_nce/euclidean/none，训练折上定）**差 −0.026**（3:9，p 0.78）；E_T@290 −0.030、φ −0.010、E_T⊕φ −0.030——四个特征臂全部输给固定选择。
读法：几何家族偏好是真实的数据集性质（WP15 ICC 0.72；本表家族 oracle − 固定最好 +0.023），但**我们手上所有可迁移的数据集描述量（原始 φ、转导响应画像 E_T、表示空间几何 GEOM）都读不出它**——它只能靠目标侧测量得到。

## 1. 标签（29 靶 × 11 目录配置，官方 @100%，掩码关，seed 0）

8 个家族在目录里；冠军家族分布 info_nce/euclidean/none 11、triplet/dot/none 10、info_nce/dot/layer_norm 3、其余 5 个各 1；猜多数 0.38；固定最好家族（全数据）info_nce/euclidean/none，家族 oracle − 固定最好 **+0.023**；先验 top-1 家族（triplet/dot/none）regret −0.037。

## 4. 读法

1. **对象对、特征不对，且已经是第三种特征**：WP15 A3（原始特征池，UCR）U 56% / R 65% < 75%；GEOM（表示空间几何）60–71% < 75%；本轮 E_T（转导响应画像，UEA）0.14 < 0.38。三种不同来源的数据集描述量在两个语料上都读不出"该用 info_nce 几何还是 triplet 几何"。
2. **为什么 E_T 在这里比在 K3 差**：K3 里 E_T 的贡献是在信任域内把"哪条配置"排好（regret@3 0.0151 vs 0.0191），那是一个 11 条配置的细粒度对象、由 11 个 GGS 探针响应量支撑；家族偏好是一个粗粒度的二选一，E_T 的 22 维在 29 靶上过拟合（岭在多数折选到最小 α 也救不了）。
3. **对分层搜索方案**：分层方案的脊梁（E 定家族）在现有特征下不成立；剩下"任务盲层 + 测量层"= 现在的先验 + SH。几何家族的 +0.023 只能由目标侧测量兑现——SH 两家族各起跑（"两版都量"的几何版）是可行的测量式设计，但那不是预测式主张。
4. **对论文**：可写"损失几何偏好是数据集级（ICC 0.72、29 靶家族净空 +0.023），但对三类数据集描述量（原始 / 转导 / 表示几何）均不可预测（两语料五次留一）"，作为 dataset-aware 预测式的一条硬边界。

## 5. 诚实项

- n = 29，8 类不均衡（两大家族 21/29）；命中率的猜多数基线按各臂可用靶算。
- 六个 LODO 靶无 φ（官方版 φ 只算了 23 靶），φ 臂与组合臂 n = 23。
- 家族标签来自 seed 0 单次官方轨迹（σ 中位 0.014）；家族 oracle 含赢家诅咒（11 选 1）。
- 预测器只试了岭（α 内层 LOO）；n = 29 上更复杂的模型只会更过拟合。
