## 0. TL;DR

1. **Q1 = 零：δ 不是任务信号的唯一杀手，"task-aware 判死"的证据升级为与 δ 无关。** 软 BCE（S1）、
   信息加权硬 BCE（S2）、经验 CDF（S1e）、软 label × 非退化 E（X）四种口径 × 3 种子，硬评估集
   within/cross shuffle 消融 **全部 Δ = 0.0000、McNemar 0/5**；软评估集加权准确率的消融差 bootstrap CI
   **逐字为 [0, 0]**（模型输出对 E 错位完全不变）。保留 0.6<P<0.97 带、不弃样，E 依然无梯度。
2. **X 交叉臂否定 DESIGN_NOTES §3.4 的"两条因果互相遮蔽"**：同时修 label 侧（软 label）与特征侧（绕过 SetTF，
   实验 1 的非退化 E）仍是零，与 S1 同档。两条因果任一都不是决定因素。
3. **Q3a 软 label 集确实含被 δ 弃掉的任务依赖质量（加权任务盲天花板 0.9525 → 0.8006）**，但零训练拆解
   （§3.3，协议外补充）显示这份质量的归属：**Handwriting 内部的跨任务分歧被噪声模型完全解释**
   （超额分歧 +0.002），**UniMiB 内部在中带有 +0.097 的真实超额分歧**，pooled 的 +0.114 主要是 HW↔UM 的
   **域级**分歧。即软 label 里的"任务信号"= 域级 + UM 内部，而比较器对这两者都零响应。
4. **Q3b 响应曲线（全项目首条）**：翻转率 0/0.1/0.2/0.3/0.4 → 留出 acc 0.785/0.786/0.768/0.737/0.693；
   下降 0.02 处 **f\* = 0.21**；而硬 δ 存活 label 的模型等效翻转率 **f_eff = 0.004**（p90 0.013）。
   **label 噪声离比较器的可感阈值差 50×**——DESIGN_NOTES §1.3-3/4（翻转曲线、自适应 k）的前提不成立。
5. **Q2 判负但读法须修正**：只用 shared-shared 训练的比较器在留出 shared-shared 对上 0.87–0.90、在 random
   参与对上 **0.53–0.57**（gap −0.33）；但全量训练的 H0 自己在两类上也差 −0.11（0.88 vs 0.77）。
   这不是"random label 分布不同"，是 **10 个 shared CLS 撑不起 19 维空间的泛化**——任务盲天花板
   0.9525 只覆盖 15% 的 label 的判断维持，且 random 参与部分的可达精度更低。
6. **正面副产品（协议外）**：软 label 让**通用排序器**更好——S1 比 H0 留出 acc +0.023（种子配对 +0.028/+0.036/
   +0.004，3/3 同向）、软 log-loss 0.80 → 0.61、高置信带 0.780 → 0.803、random 参与对 0.767 → 0.793；
   中带不变（0.649 → 0.655）。代价：不弃样后每 epoch 配对 ×2.4、训练时间 ×2.3。
7. 预测对账 **4✓ / 3✗**（§7）。成本：24 跑 ≈ 65 min GPU（两 worker 并行 ≈ 35 min 墙钟）。

  HW 0.96–1.12、UM ≈1.00。P 分带（5320 对）：pmax<0.6 占 8.4%、中带 43.9%、≥0.97 占 47.7%；中带权重质量 37.9%。

  （最大差 0.001），说明 SoftTCLSCEngine 的 w=1 硬路径与原引擎等价。

## 3. 判读表回答（协议 §5）

### 3.1 Q1：δ 是否唯一杀手 → **零**

S1/S2 的 R1–R3 中位数种子 within Δ = 0.0000、n_sig 0（协议档位"零"：<0.005 且 ≤1）；软评估集口径同零。
按预注册读法：**"task-aware 判死"的证据升级为与 δ 无关**——label 侧单因不成立（软 label 已把 0.6<P<0.97 带
全部喂进去，且 §3.3 证明这一带确实含跨任务/跨域分歧），锅不在阈值。

### 3.2 Q2：85% 同分布假设 → **判负，但机制是覆盖而非分布**

| | shared-shared（192 对） | random 参与（1128 对） | gap |
|---|---:|---:|---:|
| Cshared（只用 shared 训） | 0.865 / 0.896 / 0.870 | 0.569 / 0.527 / 0.554 | **−0.33** |
| H0（全量训） | 0.891 / 0.865 / 0.896 | 0.782 / 0.756 / 0.762 | −0.11 |
| S1（全量训、软） | 0.885 / 0.870 / 0.896 | 0.816 / 0.797 / 0.767 | −0.09 |

只见过 10 个 shared CLS 的模型对 random CLS 近乎瞎猜（0.55）——19 维配置空间靠 45 个无序对撑不起泛化。
即使全量训练，random 参与对也系统性比 shared-shared 难 0.09–0.11（shared 10 是跨 HAR 好坏排名的手挑探针，
R' 差距天然大）。**结论**：任务盲天花板 0.9525 只描述 15% 的 label；对其余 85%，"同分布"假设不成立，
且方向是**更难、更低天花板**，不是"更任务依赖"（random CLS 每任务独立采样，跨任务对照本身不存在）。

### 3.3 Q3(a)：加权任务盲天花板 → **0.8006 < 0.95**，且拆解到噪声期望（协议外补充）

| 带 | 权重质量 | 测得天花板 pooled | 噪声期望\* pooled | 超额分歧 | HW 测/期/超 | UM 测/期/超 |
|---|---:|---:|---:|---:|---|---|
| 全部（Student-t 权） | 861 | 0.8006 | 0.9143 | **+0.114** | 0.926 / 0.928 / **+0.002** | 0.840 / 0.902 / **+0.062** |
| 中带 0.6≤pmax<0.97 | 463 (54%) | 0.7058 | 0.8602 | **+0.155** | 0.878 / 0.881 / +0.003 | 0.746 / 0.842 / **+0.097** |
| 高带 ≥0.97 | 383 | 0.9342 | 0.9929 | +0.059 | 0.995 / 0.989 / −0.006 | 0.980 / 0.996 / +0.016 |
| 低带 <0.6 | 15 | 0.7865 | 0.5795 | −0.207 | （质量 4）| （质量 11）|

\* 噪声期望 = Σw·max(p,1−p)/Σw：若所有任务真方向一致、观测方向只按噪声模型翻转，任务盲天花板应落在此值。

读法：
- **Handwriting 12 任务之间没有超出噪声的分歧**（+0.002 / +0.003）：HW 内部"任务信号"= 0，这与 C2 §5
  "HW 内天花板 1.000"同向且更强（软口径也是零）。
- **UniMiB 16 任务之间有真实分歧**（中带 +0.097）：与 step0 扩容轮 E2 "分歧存在（0.852）"一致。
- **pooled 超额（+0.114）绝大部分是 HW↔UM 的域级分歧**（跨数据集排名 ρ 0.24）。
- 因此软 label 里可被 E 利用的信息 = 域级（E 明确携带，实验 1）+ UM 内部（E 数据集内区分力弱）。
  比较器对**域级信号都零响应**（cross 0.0000）——这不是 label 缺信号、也不是 E 缺信号，
  是 **BCE 下这份信号的边际收益太小**：域级分歧只占 shared-shared 质量的 11%，shared-shared 又只占
  label 的 15%，且 H0 在 shared-shared 上的实际精度 0.88 还没摸到任务盲天花板 0.95——E 支路没有被逼着上场。

### 3.4 Q3(b)：响应曲线 → **f\* = 0.21 ≫ f_eff = 0.004**

| 翻转率 f | 0 | 0.1 | 0.2 | 0.3 | 0.4 |
|---|---:|---:|---:|---:|---:|
| 留出 acc（seed 0/1 均值） | 0.785 | 0.786 | 0.768 | 0.737 | 0.693 |
| 相对 f=0 下降 | — | −0.001 | +0.017 | +0.048 | +0.092 |

曲线在 f ≤ 0.1 完全平坦，下降 0.02 处线性内插 **f\* = 0.21**；硬 δ 存活 2391 对在噪声模型下的等效翻转率
**均值 0.0042、p90 0.013**。**label 噪声不是比较器瓶颈**，差两个数量级。这也解释了 SWA / 共享种子 / k 放大
四条"压噪声"路线为什么全无起色：它们压的量本来就在比较器的感知阈值之下。

### 3.5 X：实验 1 × 2 交叉 → **与 S1 同档（零）**

软 label（label 侧修复）× 均值池化 E（特征侧修复）三种子 within/cross 全零；normal acc 0.830/0.802/0.786
与 S1 同带，且训练只要 14 s（SetTF 臂 277 s）。DESIGN_NOTES §3.4"两条因果互相遮蔽、须同时修"的假设**被否定**。

## 4. 综合判读

把实验 1 与实验 2 合起来，E 惰性的排除链现在是：

| 候选原因 | 证据 | 状态 |
|---|---|---|
| 硬 δ 剃掉任务信号 | 软 label 不弃样 → 仍零（S1/S2/S1e） | **排除为决定因素** |
| E 经 SetTF 退化 | 退化确认（实验 1 F1/F2）但绕过后仍零（F3、X） | **排除为决定因素** |
| label 噪声 | f_eff 0.004 vs f\* 0.21 | **排除** |
| label 里无任务信号 | HW 内确无（+0.002）；UM 内有（+0.097）；域级有（+0.11） | **部分成立**：信号存在但小、且集中在 UM 与域级 |
| 信号边际收益太小 / 优化不去用 | 域级信号显式存在于 E 与 label，比较器 cross 仍 0；H0 未饱和任务盲天花板 | **现在最像的解释**，未直接检验 |

诚实结论：**在本栈（2 数据集、28 切片任务、concat-MLP 比较器、BCE）下，task-aware 排序不可实现，且这一结论
对 δ 口径、噪声模型、E 通路三者都稳健**。剩下唯一未排除的是"信号太小以至 BCE 不去用"——这等价于说
可达增益上限本身很小：域级 + UM 内部的分歧质量合计约占 shared-shared label 的 11%，折到全体 label 约 2%。

## 6. Limitations

1. 噪声模型只由 4 个探针任务 × 10 shared CLS 标定（每数据集 60 个重复差）；random CLS 的噪声可能更大
   （decisive §9-L4），f_eff 因此可能被低估——但即便 ×3 仍 ≪ f\*。
2. UM 破坏制式 cell 仅 3 个，按协议并入单制式；两制式版未跑。κ=0.595 借用 UM 分解套在 HW 上（协议已声明）。
3. 软评估集的权重用 Student-t 模型（跨臂统一），中带/高带划分随之定义；经验 CDF 下天花板 0.8028，差 0.002。
4. Q2 的"覆盖 vs 分布"读法是事后解释，预注册只写了阈值；反事实（随机挑 10 个 random CLS 当"shared"训）未跑。
5. n=3 种子、GPU 三进程并发 ±0.01；"零"= |Δ| ≤ 0.005 档位，但本轮 SetTF 臂的软评估 CI 逐位为 [0,0]。
6. 翻转曲线只有 2 种子 × 4 点；f\* 由线性内插得到。
7. §3.3 的噪声期望假设"每对只有一个真方向"，对确有域级差异的对会把域级分歧记作超额——这正是我们要读的量，
   但意味着 HW 内 +0.002 的读数是"HW 内无分歧"而非"噪声模型完美"。
