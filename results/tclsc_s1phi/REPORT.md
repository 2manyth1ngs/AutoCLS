## 4. 读法

1. **"用了"与"有用"在 LODO 下分开了。** cross 消融在全域指标上极显著（92:23），说明 diff 头学到的 φ→偏好映射对未见数据集**有定义且被使用**；
   但 zero 消融只 +0.007——正确的 φ 比"平均数据集"只好一点点，错误的 φ 却伤 0.035。这是"用 7 个点学函数"的典型形状：
   模型对 φ 敏感，但目标数据集的 φ 落在训练 φ 的凸包外/边缘时，映射给出的信息接近均值。
2. **信号在粗排序，不在好半区。** φ 帮 diff 头把 M0 从 0.756 抬到 0.780（追平 hgb），M2 +0.017；M1 与 regret 不动。与 WP12 一致：
   任务盲先验在好半区信息量为零，而 φ 这种低维数据集描述量只能补粗粒度的那部分——好半区的偏好是高秩、数据集特异的。
3. **头的结论稳住了**：concat 头在 LODO 下仍不用 φ（GP3 ✓，M0 Δ +0.002），diff 头用——L3 阶段 0 的机制在真实的可迁移变量上复现。
4. **对主臂的含义**：预测式（φ→偏好）在比较器形态下能迁移的是"粗排序"层，这一层任务盲先验已经做到 0.758，φ 只加 0.02，
   且选择指标不动。要让预测式在**选择**上起作用，条件变量得对好半区有信息——候选只剩两类：真 E（表示空间，维度高、可能含更细的性质）
   和转导指纹（目标上少量探针的实测分，WP12 显示它在好半区 Spearman 0.13–0.6，是唯一在好半区非零的信息源）。
5. **不能写的**：φ 臂 task-aware 成立；φ 提升选择。可以写的：diff 头在 LODO 下对可迁移条件变量的消融显著（机制跨口径复现），
   以及"用了但在好半区无增益"这个与 WP12 互证的结构。
