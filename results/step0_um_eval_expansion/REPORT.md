## 7. 判读建议（供拍板；按协议 A 格本轮不产生 task-aware 正式结论）

1. **有效性闸**：建议按评估集探针判例采纳数据（失配=单一已知不稳 CLS 的
   进程间差、实现等价四重锚全过），环境噪声记 limitation。
2. **A 格的实质**：E1 失手不是"尺子没修好"，是"尺子修到头了还差 3–6×"——
   地板 0.042–0.045 vs 信号 p50 0.007/p90 0.017。若采纳，则协议 D 格的实质
   内容（信号存在但可达尺子够不着）在 UM 上**以强于 E3 设计的证据成立**：
   不是天花板差一点，是任务特异票**一条都够不着**（0/106）。
3. **对 v2 设计的影响**：
   - "评估侧扩容 + 两制式 δ"这条杠杆在**当前 encoder×工作点栈**上对
     task-aware **关闭**——不是池不够大（eligible≥5000 判据救不了地板）；
     两制式 δ 本身有效（0.075→0.045，白拿 40%），对通用排序 label 产量仍有用。
   - **范围声明仍生效**：以上限 UM 内。跨数据集分歧幅度未直测——但旧估计
     已作废，引用前必须用本探针同款干净口径重测（HW 侧无扩容余量，测不了）。
   - **Step 1（换 encoder）从"可选"升为"唯一活路"**：它是仅存的能同时动
     地板（轨迹稳定性）与信号幅度（headroom/表征分化）的杠杆。Step 0 原定的
     "先验尺子再建池"顺序作废——尺子已证明在本栈上无法修到信号之上，
     建池判据（eligible≥5000）只在新 encoder 通过同款探针后才有意义。
4. **论文侧（出路 X 增益）**：本探针首次把"测量地板"与"信号幅度"分离定量
   （两成分拟合 + 0/106），是负结果证据链的收口一环；顺带修正了 outlet_y
   的信号幅度高估——这本身是方法学贡献（k=1 差值作为信号幅度估计的
   噪声膨胀偏差，实测 3–4×）。

## 8. Limitations

1. 单数据集（UM）16 任务；任务特异幅度的直测不外推到跨数据集对（范围声明）。
2. 逐位锚失守：绝对量含 20be4f74 类 CLS 的进程间敏感分量（≤0.062）；
   相对量（比值、δ、天花板、守卫）为本轮内同环境量，稳健。
3. 两成分拟合假设计数与地板独立可加（方差意义）；med 与 P95 各自 2 点拟合
   无自由度做拟合优度，但四个数一致收敛于同一地板值是主要支撑。
4. 守卫 32 票样本小（75% 的 CI 宽）；但方向与地板分析一致（新增带 0.045–0.075
   处在地板噪声区间内）。
5. 基线带用 3 种子（协议 §2）；regime 判定对带宽不敏感（strict 19/160 与
   已知破坏名单吻合）。
