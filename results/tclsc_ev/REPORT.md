## 1. 设计要点（协议 §1）

- 搜索域 D = 到 T（shared-10 + GGS）最小汉明 ≤ 3 且合法；初始 = T + 200 条域内随机（中心均匀、h 均匀 {1,2,3}、NB1 `mutate`）→ Round-Robin 胜场 → 种群 20 → 10 代（p_cross 0.8 / p_mut 0.2 = 论文 p1 / p2；变异为一步局部 ±1/±2 档；后代须 ∈ D）→ 最终排名 → 前 3 条非信任域配置真跑；14 切片 = 7 折集各 `_00` + `_x00`。
- 适应度 = 该数据集 LODO 折模型（从未见该数据集）3 种子平均 P，ctx 预算 290：`ev_et` = NB1 的 ft60_hard（E_T field 头）；`ev_blind` = NB1 的 blind_diff_hard；`ev_es` = 新臂 es_field_hard（折共享 TS2Vec + Set Transformer 联合训练 + field 头，NB1 同一份训练标签、同超参）。
- 对照：`rand_u` 域内均匀 3 条新标签；`rand_nb` = NB1 该切片 6 条邻居（中心 = 该切片 k3 真值前 2，带标签信息的强对照）C(6,3) 期望。
- 真值 k1 canonical 种子；参照 ref = max(shared-10 k3 均值, GGS k1)。
- 与 AutoCTS++ 原文的出入（用户 2026-09-18 指出）：AutoCTS++ 是"全空间 − 领域知识剪掉的已知差结构"里搜、变异全档重采；EV1 是"已知好配置的汉明 ≤ 3 邻域"里搜、变异局部一步。出入在搜索域，不在算子。

## 6. 读法

1. **搜索净空 = 0，与随机邻域净空一致**。NB1 问"10 个随机邻居里有没有更好的"，EV1 问"比较器引导的进化在 2.8 万条邻域里挑出来的 3 条有没有更好的"——答案相同：best3 与随机 3 条的 best3 持平（0.728 vs 0.731），比"以真值前 2 为中心"的 NB1 邻居期望（0.743）还低。T-AHC 式目标侧进化在这个邻域里没有可赢的东西，验证方式不是误判来源。
2. **进化是代理的对手不是伙伴**：它精确地找到比较器最高估的区域（域边界、离标签最远），把 NB1 里 E_T 防住的一半高估全部还回来（+0.15 → +0.81）。这是关键判负 (b)（开放空间外推高估）在"有邻域标签之后"的复现——邻域标签只管得住汉明 1–2，管不住 3。
3. **E 的作用 = 避坏**：E_T 引导的 mean3 比均匀随机高 0.06（p 0.018）——比较器能把破坏性配置筛掉（NB1 邻居 vs 中心判对率 0.60 的同一能力），这对"从大空间里挑候选"有用，对"找到超过已知最好"无用。
4. **两种 E 的比较**：AutoCTS++ 原味 SetTF E（与比较器联合训练）在 NB1 标签下第二次学成数据集身份向量（S1E 是第一次），比较器把它当噪声（换掉 / 置零更好）；转导 E_T 至少还有粗排序与避坏。E 的来源不改变结论 1。
5. **锚的问题（用户指出）**：EV1 的搜索域锚在任务盲的信任域周围，而已有缓存显示全空间随机配置超过信任域超 δ 的切片在 HMD 0.25 / Ethanol 0.33（最大 +0.125 / +0.064）、其余四集 0——HMD / Ethanol 上确实存在信任域邻域外的更好配置。但吃到它们需要在全空间给目标排序，那正是比较器高估最严重的区域（D 检验汉明 8 提名、EV1 汉明 3 边界）；AutoCL 能在全空间搜是因为每步用目标上的真实验证精度当奖励（RL，500 次训练），不是预测器。测量式的对应物是 SH / WP8-BO。
6. **对论文**：可写"在信任域邻域内，比较器引导的进化（AutoCTS++ 部署形态）与随机采样的最优提名同带、无一超噪声，且被进化利用（预测赢率 1.00 vs 真 0.19）；AutoCTS++ 原味 SetTF E 在 7 个源数据集上学成身份向量"；不写"E 引导的搜索提升精度"。
7. **不该再做**：目标侧 NB2（官方口径六靶的进化部署）；继续训 SetTF 余下 4 折。**可做（待拍板）**：EV2-full（全空间 − 任务盲剔差区域，HMD / Ethanol 各 2 切片，≈ $1–1.5）测预测器能否替代 AutoCL 的测量；或测量式（HMD / Ethanol 全空间随机 30–50 条真跑，≈ $2–3）直接量净空分布。
