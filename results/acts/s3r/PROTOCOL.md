**会话定位**（2026-09-27 审计第 2 + 3 步，memory `wp17-acts-audit-0927-autocts-contradictions`）：
- S3-C 严格复现臂 A（E_pt + SetTF + concat）停在第 1–14 个 epoch，最优点训练 BCE 0.59–0.66，与任务盲臂 D 相同：**E 在训练任务上都没被用上**。

  1. 早停用"留出一个源"的验证损失，测的正是跨源迁移，E 还没开始拟合就被截断。AutoCTS++ 代码的验证集其实是**同一训练任务里留出的一批架构**。
  2. linear 配对每 epoch 约 7,200 对，远低于 AutoCTS++ 的全配对（每 epoch 数十万对）。
  3. 47% 的配置低于探针地板，训练配对的 2/3 涉及失败配置；失败对失败的标签基本是噪声，且因任务而异，会奖励 E 去记任务身份。
- 用户 2026-09-27 拍板：第 2 步（清洗标签）与第 3 步（按 AutoCTS++ 实际做法重训）合成一个实验，在实验室服务器多卡并行。
- 结构与 E 输入保持严格复现（E_pt + SetTF + concat 头），只改标签、验证口径和训练量；另训一个同设置的任务盲对照。

产物 `results/acts/s3r/`；代码 `scripts/105_acts_s3r.py`（复用 89 的模型 / 打分器 / 窗口读取 / RR 排序、91 的 L4 标签与权重、88 的 cross_maps、84 的 regret）；单测 `tests/test_acts_s3r.py`；服务器 `scripts/pa_pod/acts_lab_run_s3r.sh`。

## §1 数据与标签
- 语料同 S3-C：160 任务 / 17 源，每任务 shared-30 + random（10–20 条），binned φ（116 维）。
- **标签值** = L4（S3-E）：shared 用两种子终点均值，random 用种子 0 终点。
- **失败** = 标签值 ≤ 该任务探针地板（iters = 0 随机初始化 encoder + SVM 的精度均值，`84.load_s2` 的 `pfloor`）。
- **配对与权重**（任务内全部有序对，两个方向都放，= AutoCTS++ quadratic loader）：
  - 可用对可用：y = 1[r_a > r_b]，权重 = `91.l4_weight`（|Δ| 相对种子噪声，封顶 1；相等为 0 即不进）；
  - 失败对可用：y = 可用者胜，**权重 0.25**，且**这类配对的梯度不回传进 SetTF**（任务向量 detach）。E 的表示只由可用对可用的配对塑形；比较器的其余部分仍学"避开失败配置"。
  - 失败对失败：不进损失。
- **验证集**（= AutoCTS++ 同任务留出架构的对应物）：每个训练任务按固定种子留出 ⌊n_random / 4⌋ 条 random 配置（20 条时留 5 条），它们不参与训练配对。验证配对 = 至少一端是留出配置的同任务配对，权重规则同上。早停看验证加权 BCE。

## §2 模型与训练
- **E 臂**：`89.build_model("A")`（TCLSC concat 头，TaskSetEncoder 256 → 256，E_pt 窗口，训练时每次抽 32 窗）。
- **B 臂**（任务盲对照）：`89.build_model("D")`，其余完全相同。
- Adam lr 1e-4（S3-C 同值），BCE 加权。
- 批次按任务分组：每批 4 个任务 × 各 64 对 = 256 对。每批只做 ≤ 4 次 SetTF 前向，也就能负担全配对。
- 每 epoch = 全部训练配对过一遍（约 21 万对）；最多 40 epoch，验证损失 patience 5（论文值），取最优 epoch。
- 6 折（HW / PS / UWave / Cricket / Ethanol / SCP1，同 S3-C），**训练用其余 16 个源的全部任务**（不再留验证源），3 个种子（0 / 1 / 2）× 2 臂 = **36 次训练**。

## §3 读数
**样本内（训练任务，每个模型各算）**：
- 训练配对上的加权准确率（只算可用对可用），分别用本任务的 E 和换 E（换成另一训练源同 OA 行任务的 E，`88.cross_maps` 在训练源内做，偏移 1–4 取均值）。
- 另报：失败对可用的准确率、验证配对准确率（本 E / 换 E）、训练 / 验证损失、epoch 数、累计配对数。

**留出源（6 折 56 个留出任务，= S3-C 考卷）**：
- 每臂 3 种子的 P 矩阵取均值 → RR 排序 → shared-30 上 `84.regret_at_k` 的 regret@3 / regret@1。
- 换 E：`88.cross_maps` 偏移 1–16 的他源 E，取均值。
- random 段 Spearman（RR 名次 vs R0，任务中位数）。
- E 的源内 / 源间余弦（身份型检查）。

## §4 门与读数码
- **G-IN（E 在样本内被用上，前置门）**：Δ_in = 样本内可用对可用准确率（本 E − 换 E）。18 个 E 臂模型的均值 ≥ +0.02，且 18 个模型的精确符号翻转 p < 0.05，且 ≥ 5/6 折（3 种子均值）为正。
- **G-OUT 价值**：d = regret@3(B 臂) − regret@3(E 臂)，56 任务均值 ≥ +0.003，任务级 Wilcoxon p < 0.05，且 ≥ 4/6 源为正。
- **G-OUT 内容**：d = regret@3(换 E) − regret@3(E 臂)，均值 ≥ +0.003，任务级 Wilcoxon p < 0.05，且 ≥ 4/6 源为正。
- 读数码：G-IN ✗ → **S3R-E-UNUSED**；G-IN ✓、G-OUT 价值 ✗ → **S3R-E-FITS**；G-IN ✓ 且 G-OUT 价值 ✓ → **S3R-E-WIN**；G-OUT 内容过再加 **+CONTENT**。
