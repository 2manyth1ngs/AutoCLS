## §1 两阶段选择（每臂、每数据集，候选池 = S3-Z 的 U）
1. **第一阶段（已跑，复用 S3-Z）：** U 中每条配置的 3 折 CV 均值（折划分种子 = S3-Y / S3-Z 同一个，训练种子 0）。按均值取前 4 名作决赛名单，平局取 10 成员集成分数高者。
2. **第二阶段（新跑）：** 决赛 4 条各再做 2 次重复 3 折 CV：
   - 第 r 次（r = 1、2）用新的分层折划分（折种子由数据集名与 r 派生，固定），训练种子 = r；
   - 只用官方 TRAIN，TEST 不读。
3. **选 1：** 决赛 4 条按 3 次重复共 9 次折评估的平均准确率选最高者；平局依次取第一阶段均值高者、集成分数高者。
4. **最终：** 选中者在完整官方 TRAIN 上训种子 0 / 1 / 2，报 TEST 均值。
5. **描述用：** 决赛 4 条都补齐官方种子 0 / 1 / 2 的 TEST，用来评估决赛内的选择质量；这些数字不参与选择。

## §2 门与读数码
- **主门（NEW 两阶段 6 集 3 种子 TEST 均值）：**
  - > InfoTS_s 0.6468 且 > TS2Vec 0.6243 → **S3ZP-BEATS-BOTH**；
  - 只 > TS2Vec → **S3ZP-BEATS-TS2VEC**；
  - 否则 → **S3ZP-BELOW**。
- **后缀（对同池单阶段选择 S3-Z NEW 0.6279）：** ≥ +0.010 → **+UP**；≤ −0.010 → **+DOWN**；其间 → **+FLAT**。
- **后缀 +E：** NEW ≥ NEW_B + 0.010。
- **描述项（每臂）：**
  - 逐数据集表：单阶段选中 / 两阶段选中 / 决赛 4 条内的 3 种子 oracle；
  - 两阶段改变选择的次数；
  - 决赛名单是否包含 U 中种子 0 TEST 最好者；
  - 两阶段相对决赛 oracle 的选择损失（3 种子口径）；
  - 9 次折评估的均值与 TEST 的 Spearman。
- 6 个数据集，不做显著性声明；差 < 0.01 视为持平。
