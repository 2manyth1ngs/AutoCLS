## §1 数据与口径
- 训练池 160 任务 / 17 源（`84.load_s2()["pool"]`）：shared-30 两种子终点 end0 / end1，钉底 z 画像 Z（两种子均值，中位钉底）。
- random-20：`results/acts/s3c/data.npz` 的 `R0`（种子 0 终点）与 binned φ（`vec`，50 × 116，前 30 = shared，与 Z 列序逐位对齐，脚本内断言）。
- 17 源留一个源（LOSO）；6 个 UEA 折源（HW / PS / UWave / Cricket / Ethanol / SCP1）另列。
- **主读数 regret@3 = `84.regret_at_k`**（S3-A 系列标准）：oracle = 种子 0 最高；按打分取前 3，再用种子 0 在前 3 里挑 1；regret = 种子 1 上 oracle − 所选。副读数 regret@1。

## §2 E 与检索
- **E_pt**（主 E）：每任务 TS2Vec 窗口表征均值 256 维（`s3b/E_pt/_means.npz`）。
- 副 E：**E_sh**（留出源 s 用 `s3b/E_sh/{s}/_means.npz`，该共享 TS2Vec 没见过 s）、**E_A**（`s3n/ea.npz` 25 维）、**E_TF**（`s3o/et.npz` 的 ETF 22 维）。
- 相似度：每维用训练折任务的均值 / 标准差标准化后取余弦；近邻只在训练折任务里找（绝不含留出源）。
- 近邻画像 = k 个近邻任务 Z 的等权均值。
- **k 的选择**：网格 {3, 5, 10, 20, 40}，在训练折的 16 个源上做内层留一个源，按源加权平均 regret@3 最小选 k（平局取大 k）。

## §3 臂
**目录层（shared-30）**：
- **BLIND**：训练折任务 Z 的均值（= S3-A 任务盲 μ）。
- **KNN**：近邻画像，k 内层选。
- **KNN10**：k 固定 10（审计里看过的值，只作描述）。
- **KNN-X**（内容对照）：目标任务的 E 换成 `88.cross_maps` 偏移 1–16 映射到的他源任务的 E（k 同 KNN），16 次取均值。
- **ORACLE**（天花板，描述）：用目标自己的种子 0 钉底画像与训练任务 Z 的 Spearman 挑 10 个近邻。

**目录外（random-20，为全空间搜索做准备）**：
- 每任务标签 y = 该任务 50 条（shared 用 end0、random 用 R0，都是种子 0 终点）的中位钉底 z；特征 = binned φ。
- **SUR-BLIND**：岭回归，在训练折全部任务的 (φ, y) 上拟合。
- **SUR-KNN**：同一岭回归，只在该目标任务的 k 个 E 近邻任务上拟合（k 同 KNN）。
- **SUR-X**：SUR-KNN 的近邻按换过的 E 找（偏移 1–16 取均值）。
- 两臂的 α 各自在内层留一个源里按"random-20 平均 Spearman 最大"从 {1, 10, 10², 10³, 10⁴, 10⁵} 选（平局取大 α）。
- 读数：留出任务 random-20 上预测分与 R0 的 Spearman（任务均值）；描述项：前一半 Spearman、代理在 shared-30 上的 regret@3、random-20 预测前 3 的高估（预测 z − 真 z）。

## §4 门与读数码（主 E = E_pt）
统计单位 = 源：每源先取任务均值，再对 17 个源的差做精确符号翻转检验（2¹⁷，双侧）；CI = 按源重抽 bootstrap 10,000 次（任务加权）。
- **G1 价值**：Δ₁ = regret@3(BLIND) − regret@3(KNN)，源加权 Δ₁ ≥ +0.003 且 p < 0.05。
- **G2 内容**：Δ₂ = regret@3(KNN-X) − regret@3(KNN)，源加权 Δ₂ > 0 且 p < 0.05。
- **G3 目录外**：Δ₃ = Spearman(SUR-KNN) − Spearman(SUR-BLIND)，源加权 Δ₃ ≥ +0.03 且 p < 0.05。
- 读数码：G1 ∧ G2 → **S3Q-RETR-WIN**；只 G1 → **S3Q-RETR-VALUE**；只 G2 → **S3Q-RETR-CONTENT**；都不过 → **S3Q-RETR-NULL**；G3 过再加 **+SPACE**。
- 副 E（E_sh / E_A / E_TF）同样算 G1–G3，只描述，G1 另报 4 个 E 的 Holm 校正 p。
