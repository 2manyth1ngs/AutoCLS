## §1 坐标条件（对留出任务 t；â_m 为成员 m 的 E 坐标，a 为真实坐标）
| 条件 | (c₁, c₂, c₃) | 含义 |
|---|---|---|
| Z | (0, 0, 0) | 不给任务信息（轴瓶颈比较器的任务盲部分） |
| P | (â₁, â₂, â₃) | 现在的部署（= A′） |
| P1 | (â₁, 0, 0) | 只用 E 预测的第一维 |
| T1 | (a₁, 0, 0) | 只给真实第一维 |
| T1+P23 | (a₁, â₂, â₃) | 第一维换成真实，其余仍用 E |
| P1+T23 | (â₁, a₂, a₃) | 第一维用 E，其余换成真实 |
| T12 | (a₁, a₂, 0) | 前两维真实 |
| T | (a₁, a₂, a₃) | 全真实（= O′） |

比较器 = S3-J 的 I′ 集成（6 折 × 5 成员），λ = 0 胜场均值。

## §2 读数
- **R1 目录内排序**（56 个留出任务）：shared-30 上 regret@3（seed 0 选、seed 1 评）。
- **R2 搜索区域排序**（48 任务考卷）：每个任务的候选池 = shared-30 ∪ S3-C 到 S3-J 所有臂提名过、两个种子都有真值的配置；池内 regret@3（seed 0 选、seed 1 评，oracle 取池内 seed 0 最好者的 seed 1）与池内 Spearman（比较器胜场 vs 两种子均值）。这是最接近搜索的零 GPU 读数，因为它包含了搜索真正去过的目录外配置。
- **R3 名单外**：56 个留出任务的 random-20 中位 Spearman。
- **兑现比例**：对每个读数，(条件 − Z) / (T − Z)，即该条件拿到了全真实坐标增益的多少。

## §3 判读规则（先于数据）
以 R2 的兑现比例为主（与搜索最相关），R1 作辅助：
- **a₁ 为主**：T1 ≥ 70%，且 T12 − T1 < 20%。下一步改 E 专攻 a₁ 的精度。
- **a₁ + a₂**：T1 < 70%，但 T12 ≥ 80%。下一步 E 需要同时预测好 a₁ 与 a₂。
- **需要全部三维**：T12 < 80%。
- 另报 T1+P23 − T1：E 现在预测的 a₂ / a₃ 是帮忙还是添乱（负值 = 添乱，下一步可只用 a₁）。
- 另报 P1 − P：只用 E 的 a₁ 是否比现在三维都用更好。
