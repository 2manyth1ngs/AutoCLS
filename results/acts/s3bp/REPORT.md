## §0 诚实账
1. **C0 通过（修过一次）**：
   - μ-only 与 field-④ 的中位 Spearman（0.1433 / 0.1983）与 S3-A′ 逐位相同；
   - 任务盲 / ④ / ③ 的 shared regret@3（0.021251 / 0.009772 / 0.006109）与 S3-A 逐位相同。
   - 初版代码把这三个参照写死成四舍五入值（0.02131 / 0.00984 / 0.00611），导致 C0 误报 ✗。已改为直接读 S3-A 的 `analysis.json`（`c0_shared_refs`）；只重算了 C0 字段，主分析没有重跑。
2. **α 触到网格上界**：E_sh r = 8 在 17/17 折都选中 α = 10⁴（网格 1–10⁴）。说明内层 LOSO 想要更强的收缩，交互项被压得很小；上界之外的表现未知。这是协议网格的局限，本轮不改网格。
3. **口径**：
   - PCA / 标准化只在外层训练任务上拟合；
   - 内层 α 选择沿用外层的 PCA、列标准化与 E_sh 编码器（只影响 α，不触及外层留出源）；
   - ridge 用按源累加的充分统计量 + 特征分解解出，与逐行 ridge 在数学上等价（外层标准化口径）。
4. 无事后分析。

## §2 读法
- **结构比 E 的来源更要紧**：E_sh 在 S3-B 里（回归 a(t)、K ≤ 3 低秩）是 0.019，在 field 里是 0.0096；E_pt 从 0.014 到 0.011。这与 WP16 L3 的历史读数同向——任务向量能否被用上，取决于头部结构，E 本身次之。
- **目录内选择有价值，名单外排序没有**：field-E 的 random-20 Spearman 与 μ-only 同带（0.11–0.15），Δ50 ≥ 0。E 帮助在 30 条目录配置里挑对，却不能给新配置排序；S3-A′ 的 SPACE-MU-FAIL（主效应外推失败）E 救不了。
- **内容依赖只是趋势**：cross-E 让 E_sh r = 8 的 regret@3 从 0.0096 退到 0.017，吃掉约六成增益，但源级检验 p 0.50（17 个源里正负参半）。E_pt r = 16 的 +0.006 同样不显著。这里既不能说"用到了任务内容"，也不能说"只是结构效应"。
- **r 不单调、α 触顶**：r = 8 最好、r = 16 变差，且 α 选在上界，说明交互项只有被强力收缩时才不伤人——信号弱，模型处在"刚好不过拟合"的边缘。
- **与 ④ 的比较**：E_sh r = 8 与 ④ 打平（0.0096 vs 0.0098），但它不需要任何 @25% 探针：成本约 0.005 当量 vs 1.0 当量。部署时它可以用来替代 ④ 的 4 条探针；能否在 ④ 之上叠加（E_sh-field ⊕ ④）本轮没测。

## §4 下一步（待拍板）
这是待确认的正信号，建议先做**零 GPU 的确认版**，再决定要不要为 S3-C 花 GPU。确认版须预注册：
1. α 网格向上扩到 10⁵–10⁶（本轮触顶）；
2. r 的选择改为内层 LOSO 选，不再固定 r = 8；
3. 内容检验改为多次 cross 指派（例如 16 种循环偏移取平均），提高功效；

如果确认版仍成立，S3-C 的 field 副臂（配对训练的 T-CLSC）就有了具体的前置证据；如果不成立，S3 三段按负结果收口。
