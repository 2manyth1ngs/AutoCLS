## §0 已看过 / 已核对

- UT、UT-ENS 全部读数（11 靶 TEST 已用两次，本探针第三次；只作“开 vs 关”的同批对比）。

  1. 元学习器目标只有保真度（标签交叉熵），论文里的多样性项在代码中被注释掉；
  2. 每个 batch 只有 aug_p1 = 0.2 的概率增强，增强时为 7 种变换的 softmax 加权混合（权重加 logistic 噪声采样，温度 1）；
  3. 两视图 = 增强混合 vs 原始 x；
  4. 元学习器每 2 遍数据（meta_epoch = 2）做一整遍更新，meta_lr = cls_lr = 0.01，meta_beta = 1。
- 官方 TS2Vec / InfoTS 的 DataLoader 用 `batch_size = min(batch_size, N)`；我们的 `cl_trainer` 在 N < batch 且 drop_last 时报错（UT 里 SWJ tcv0）——已知偏差，本轮不改。

## §1 学增强的实现（`aug_learn = "sup"`，忠实于官方代码）

- **候选变换（7 种，官方参数）：**
  - 子序列（整批同一 [start, end) 外置零）；
  - 遮挡（整批同一 10% 窗置零）；
  - 抖动 N(0, 0.3)；
  - 缩放（逐样本逐通道乘 N(1, 0.5)）；
  - 时间扭曲（100 个变速段、最大速比 10）；
  - 窗口切片（逐样本截一半再线性插值回原长）；
  - 窗口扭曲（逐样本 30% 窗按 0.5 / 2 倍变速，再插值回原长）。
  - 时间扭曲在官方代码里依赖 tsaug，这里用 torch 线性插值实现等价语义（论文未给全，按 tsaug TimeWarp 语义补全）。
- **混合权重：** w = softmax((q + logistic 噪声) / 1)，q ~ N(0, 0.01²) 初始化。
- **每个 batch：** 以概率 0.2 取 v₁ = Σᵢ wᵢ tᵢ(x)，否则 v₁ = x；v₂ = x。
  - 之后接本 CLS 的 crop（两视图共享裁剪坐标，保证时间对齐）、编码器、嵌入变换、CLS 对比损失。
  - **CLS 的 5 个非 crop 增强字段与 order 在学增强开时不生效**（被学增强取代）。
- **元学习步：** 每第 2、4、6… 遍数据开始前，对完整 TRAIN 做一遍：编码器 eval；zᵥ / zₓ = 时间维最大池化；最小化 CE(h(zᵥ), y) + CE(h(zₓ), y)，同时更新 q 与分类头 h（AdamW，lr 0.01）。不计入 max_iters。
- **标签：** 只用官方 TRAIN 标签（= InfoTS_s 口径）；TEST 不碰。
- **关闭时：** `aug_learn = "none"`（默认）与现行训练器逐位相同（单测钉死）。
- **缓存键：** 选项只在显式给出时进入键载荷，旧格键逐字节不变（单测钉死）。
- **试点阶段只作运行选项**（不进 CLS 字段、不进搜索）。只有本探针过门，才升级为 CLS 扩展字段、补源标签、接入 T-CLSC。

## §2 目标侧上限探针（UT 的 11 个未见靶，官方口径，单种子 0）

- **配置：**
  - 每靶 UT-ENS 计划里 ME 臂的 CV 前 3 条（33 条）；
  - 每靶加一条参照 = TS2Vec 等价 CLS（`35.TS2VEC_EQUIV`），学增强开 / 关各一次，即“固定 TS2Vec 策略 + 学增强”的 InfoTS 式对照。
- **作业：** 每靶 1 个。前 3 条各训练 aug_learn = sup，得单模型精度与最后截点表示；三者逐块 L2 拼接 → 官方 SVM（= UT-ENS 口径）；参照开 / 关各训一次。
- **关闭侧的对照值：** 前 3 条单模型与集成的 aug off 种子 0 读数取自 UT-ENS（同配置、同种子、同管线）。

## §3 门与读数码（单种子 0，11 靶均值）

- **主门（集成 ME，学增强开 − 关）：**
  - Δ ≥ +0.02 → **AL-HEADROOM**（升级为 CLS 扩展字段、补源标签、接入 T-CLSC）；
  - +0.01 ≤ Δ < +0.02 → **AL-WEAK**；
  - Δ < +0.01 → **AL-FLAT**（学增强在我们的管线里不抬上限，按用户约定转编码器搜索讨论）。
- **描述项：**
  - 单模型 33 条开 − 关均值与逐集胜负；
  - TS2Vec 等价 CLS 开 − 关（InfoTS 式机制本身在我们管线中的作用）；
  - 集成开 vs TS2Vec 0.5796 / InfoTS_s 0.6308；
  - 学到的混合权重。
- 差 < 0.01 视为持平。AF / SWJ 的 TEST 只有 15 个样本。
