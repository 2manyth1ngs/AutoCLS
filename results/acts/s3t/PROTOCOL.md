# WP17-ACTS S3-T PROTOCOL：训练配对加差值门槛（|Δ| > c·SE 才进训练）

**会话定位**：
- S3-R′（早停改验证准确率）让严格复现的 T-CLSC 真正用上了 E（样本内换 E 掉 0.079），但留出源只 +0.0024。
- 用户 2026-09-27 提出试回"标签差值大于门槛才进训练"：此前 ACTS 线一直不设门（S3-R′ 只用软权重 min(|Δ| / 2SE, 1)）。
- 历史约束一句话：早年用绝对 δ 硬过滤、单种子标签时，好配置之间的配对只剩 1.6–4.3%，数据集层面的信号被滤掉。所以本轮门槛按每任务噪声（SE）相对设，并先统计保留比例（见 §0），不测会把好半区配对滤到 10% 以下的档。

**唯一改动**：训练用的可用对可用配对改为硬门槛——|Δ| > c·SE 才进训练，进入的权重为 1，其余剔除（SE = 该任务前一半噪声 σ × √(1/n_a + 1/n_b)，与 L4 同一个 σ）。两档 c ∈ {1, 2}。
- 失败对可用配对不变（权重 0.25、不回传 SetTF）；失败对失败仍剔除。
- 验证配对与早停判据不变（S3-R′：软权重，验证加权准确率，patience 5），这样模型选择的尺子与 S3-R′ 相同，只有训练输入变。
- 模型、种子、折、批次、样本内 / 留出读数的配对定义都与 S3-R′ 相同。样本内读数仍按 S3-R′ 的软权重全部可用对计，不按门槛后的训练表。

产物 `results/acts/s3t/g1`、`results/acts/s3t/g2`；代码 = `scripts/105_acts_s3r.py` 加 `--gate c`（默认 0 = S3-R / R′ 原样）与 `--compare-ref`；单测 `tests/test_acts_s3r.py` 增例；服务器 `scripts/pa_pod/acts_lab_run_s3t.sh`（标签沿用 `results/acts/s3r/labels.npz`）。

## §1 臂与规模
每档 c 各跑 E 臂（E_pt + SetTF + concat）与 B 臂（任务盲），6 折 × 3 种子 → 2 档 × 36 = **72 次训练**。

## §2 门与读数码（每档各判）
- **G-GATE（门槛对 E 臂是否有用，主门）**：d = regret@3(S3-R′ 的 E 臂) − regret@3(本档 E 臂)，56 个留出任务、3 种子 P 均值 → RR；d ≥ +0.003，任务级 Wilcoxon p < 0.05，≥ 4/6 源为正 → **S3T-GATE-HELPS**；d ≤ −0.003 且 p < 0.05 → **S3T-GATE-HURTS**；否则 **S3T-GATE-NULL**。两档的 p 另报 Holm 校正。
- 同时报 S3-R 的三道门（G-IN / G-OUT 价值 / 内容，本档 E 对本档 B），读数码 S3R-E-*。
- 描述：留出任务 shared-30 可用对可用加权准确率（S3-R′ 软权重口径）、好半区准确率、每 epoch 配对数、最优 epoch。

## §4 成本与执行
- 实验室 8k-4090 多卡，72 次训练，预计 60–90 min（门槛后每 epoch 配对变少，单次更快）。
- 拉回后：两档各 `105 --analyze --outdir results/acts/s3t/g{1,2}`，再 `--compare-ref results/acts/s3rp` 出 G-GATE。
- 结论只按读数码报告；不追加新档或新臂。
