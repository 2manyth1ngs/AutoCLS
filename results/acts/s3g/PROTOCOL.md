# WP17-ACTS S3-G PROTOCOL：L3 源侧对抗扩充（一轮）

**会话定位**：S3-F（S3F-E-NULL）在 48 任务考卷上显示：
- 修好训练的 E 臂不赢任务盲；
- 所有比较器引导的全空间搜索都略低于目录任务盲前 3（任务盲 B −0.003 / −0.005）。

比较器在"搜索会去的区域"读不准，比 E 更是瓶颈。用户 2026-09-27 拍板做 L3 源侧对抗扩充。

**L3 的做法**：在训练源上用当前比较器跑一遍与部署相同的搜索，把它提名的配置真跑出来、并入标签、重训。这样比较器在搜索区域里有真值可学，目标侧仍然零样本。

产物 `results/acts/s3g/`；代码 `scripts/94_acts_s3g.py`（复用 89 / 91 / 92 / 93）；单测 `tests/test_acts_s3g.py`；服务器 `scripts/pa_pod/acts_lab_run_s3g.sh`。

## §0 已看过的读数（如实声明）
- S3-C / S3-E / S3-EA / S3-F 全部读数（48 任务考卷上的 B / E / F / R / 目录前 3、排序读数、训练曲线）。
- 考卷功效：48 任务最小可检出差 ≈ 0.014（S3-F §0）。
- **没看过**：比较器在训练源搜索区域的预测与真值之差；任何扩充后的模型读数。

## §1 扩充数据（每折独立）
- **提名用哪个比较器**：S3-EA 的任务盲集成 B（5 种子，每折一套）。理由：它排序最好，E 在 S3-EA / S3-F 都没贡献；它的提名就是任务盲部分实际会去的区域。
- **在哪些任务上提名**：折 f 的每个训练源（17 源去掉 f 与 f 的验证源，15 个）取 OA 行 a00 与 a04，每折 30 个任务。
- **怎么提名**：与部署相同的搜索（Ks 20,000 → 分块 → 进化 10 代，λ = 1，采样 / 进化种子同 S3-C 的 `run_seed_for(t, "s3c_ks" / "s3c_evo")`），取最终种群前 5 条。已在该任务 shared-30 / random-20 里的配置跳过。
- **真值**：seed 0，`ts2vec_official` cv5 终点（与 random-20 的 R0 同口径，出错格丢弃）。
- **防泄漏**：
  - 折 f 的提名只由折 f 的比较器产生（它没见过 f）；
  - 新标签只加进折 f 的训练集；
  - 验证源与留出源都不扩充。
  - 同一（任务, 配置）若被多个折提名，真值格只跑一次、各折各自使用。
- **预测—真值差（机制读数）**：每条提名记下 B 集成预测它胜过该任务 shared-30 各条的平均概率（预测胜率），真值胜率 = 它的 seed-0 终点高于 shared-30 各条 seed-0 终点的比例。差 = 预测 − 真值（正 = 高估）。

## §2 重训
- **B′**：同 S3-EA 的 B（field 头任务盲、L4、5 种子 × 6 折、同早停），训练集 = 原标签 + 本折扩充标签（扩充配置单种子，n = 1，L4 权重同 random）。
- **F′**：同 S3-F 的残差式 field-E（冻结 s₀、field_w 末层置零、lr 3e-5、辅助 0.1、每 1/4 epoch 验证），起点换成同种子同折的 **B′**，训练集同 B′。

## §3 考卷与读数（48 任务，同 S3-F）
- 臂：**B′-lcb**、**F′-lcb**（48 任务新搜，λ = 1，采样 / 进化种子同前）；对照沿用 S3-F 的 B-lcb / F-lcb / E-lcb / R / 目录前 3 / 目录 oracle。
- 两种读法：3 选 1（seed 0 选、seed 1 评）、3 条平均（两种子均值的平均）。
- **主对比 Δ_L3 = B′-lcb − B-lcb**：
  - **S3G-L3-WIN**：3 条平均 Δ ≥ +0.010，且任务级 Wilcoxon p < 0.05，且 ≥ 4/6 源为正，且 3 选 1 的 Δ > 0；
  - **S3G-L3-HURT**：3 条平均 Δ ≤ −0.010，且 p < 0.05；
  - **S3G-L3-NULL**：其余情况。
- **后缀**：
  - **+CAT-PAR**：B′-lcb 在两种读法下都 ≥ 目录前 3（点估计）；
  - **+E**：F′-lcb − B′-lcb 的 3 条平均 ≥ +0.010，且 p < 0.05，且 ≥ 4/6 源为正，且 3 选 1 > 0。
- **描述项**：
  - 预测—真值差：扩充提名（B 在训练源上）；考卷提名（B 对 B-lcb、B′ 对 B′-lcb、B′ 对旧 B-lcb、F′ 对 F′-lcb），考卷真值用两种子均值对 shared-30 两种子均值；
  - F′ − F、B′ − 目录 oracle、逐源表、奇 / 偶行分开；
  - 排序：B′ / F′ 集成在 56 个留出任务上的 regret@3、random-20 中位 Spearman；F′ 的 16 次换源 Δ。

## §4 读法（先于数据）
- **L3-WIN**：比较器读不准搜索区域是搜索输给目录的原因，L3 能修；可考虑第二轮与部署口径对表。
- **L3-NULL，但高估明显下降**：L3 修正了校准，但搜索区域里真实可赢的配置不多（与 S3-A′ 名单外净空 +0.005 一致），比较器搜索的上限接近目录。
- **L3-NULL，高估也没降**：一轮 150 格 / 折的扩充量不足以改变比较器；需要更多轮或更多提名。
- **+E**：扩充后 E 项开始起作用。

## §6 成本（共享 4090；按空闲显存分槽）
