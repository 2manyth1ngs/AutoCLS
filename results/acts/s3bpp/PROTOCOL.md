## §1 五项改动
1. **α 网格扩展**：α ∈ {1, 10, 10², 10³, 10⁴, 10⁵, 10⁶}。α 选择规则不变：内层 LOSO 最小化 MSE，平局取大。报每臂各折选中 α 的分布，以及选到新上界 10⁶ 的折数。
2. **r 由内层选**：r ∈ {4, 8, 16}。每个外层折内：
   - 对每个 r，按上一条选出 α_r；
   - 在同一组内层留出源上，用 α_r 的预测算 shared-30 的 regret@3（S3-A 口径）；
   - r\* = 内层 regret@3 最小者，平局取小 r。

   外层留出源用 (r\*, α_r\*) 预测。另报 r 固定为 4 / 8 / 16 的全表（只报，不进门）。
3. **多次 cross 指派**：对留出源每个任务，依次用池顺序中偏移 k = 1…16 的其余 16 个源（同 OA 行号，行号不存在取第 0 行）的 E 替换，得 16 个 cross 预测。
   - cross regret@3 = 16 次的均值；
   - Δ_cross = cross − 本身，源聚类 CI + 源均值 Wilcoxon；
   - 另报"16 次里比本身更差的份额"的均值。
4. **field-E ⊕ ④ 臂**：u 扩为 [u(t), a₁^④(t)]，即 S3-B′ 的 E 主成分再加一列。a₁ 沿用 S3-A′ field-④ 的口径：训练任务用折内投影 a₁，留出任务用 ④ 估出的 â₁。r 仍内层选（E 部分的 r）；目标侧成本 = ④ 的 1.0 当量 + E 成本。
5. **多臂校正**：
   - E-only 两臂（E_pt、E_sh）的 F1 / F2：Holm 校正到 2 臂；
   - F3 用 Bonferroni 的 97.5% 源聚类 CI 上界；
   - 组合两臂（E_pt ⊕ ④、E_sh ⊕ ④）的 F5：Holm 校正到 2 臂。

## §3 门（先于数据）
| 门 | 定义 | 臂 |
|---|---|---|
| F1 内容 | Δ_cross > 0 且 Holm p < 0.05 | E-only 两臂 |
| F2 价值 | vs 任务盲 ≥ 0.010 且 Holm p < 0.05 | E-only 两臂 |
| F3 替代 ④ | (E − ④) 的 97.5% CI 上界 ≤ +0.005 | E-only 两臂 |
| F4 名单外 | random-20 中位 Spearman ≥ 0.50 | E-only 两臂 |
| F5 叠加 | regret@3(④) − regret@3(E ⊕ ④) > 0 且 Holm p < 0.05 | 组合两臂 |

- **读数码**：
  - 同一个 E-only 臂 F1 ∧ F2 → **FEC-CONFIRMED**（E 有价值且内容被用上）；
  - 否则某臂 F2 ∧ F3（与 S3-B′ 同形）→ **FEC-VALUE-ONLY**（价值成立，内容仍未证实）；
  - 否则 → **FEC-NOT-CONFIRMED**。
- 后缀：任一组合臂过 F5 → **+ADD**；任一臂过 F4 → **+SPACE**。
