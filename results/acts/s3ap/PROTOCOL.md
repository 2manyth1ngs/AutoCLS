## §2 任务 3：探针数曲线
### 2.1 做法
- 探针数 k ∈ {2, 4, 6, 8, 12}，截点 @25% seed 0；另加 k = 4 @50% seed 0。
- 探针特征（任意探针集 P、截点 c）：X = [acc_c[P] − mean(acc_c[P]), mean(acc_c[P]) − majority]，共 k + 1 维。
- **贪心选探针，完全嵌套**：
  - 在给定的训练任务集上做前向选择，最多选 12 条。每步从 shared-30 里挑一条加入，使"探针特征 → 折内 A（3 个分量）"的 ridge 在训练源内层 LOSO 下的平方误差和下降最多。选择时 α 固定为 10，最终 ridge 仍按 S3-A 规则选 α。
  - 选择过程按训练集缓存，k 取前 k 条。
  - 外层折与 K 选择的内层折都在各自的训练集上重跑贪心，外层留出源从不参与选择。
- 参照点：S3-A ④ 手选的 4 条（原特征）。复现值必须 = 0.010，作为 C0 自检。
- K 与 α 同 S3-A：K 由内层 LOSO 按 regret@3 选。

### 2.2 读数
- 每个 k 报：ρ_a1 [CI]，regret@1 / @3 [CI]（30 候选），成本。若任务 1 得 SPACE-OK，再加 50 候选版。
- **同成本直接测量 Mk**，两版，取 regret@3 较低的一版作对照（对"模型有增量"的结论而言是保守的）：
  - Mk-a = 探针里 acc_c 最好的 1 条 + 任务盲 μ 前 2；
  - Mk-b = 探针里 acc_c 前 3（k ≥ 3）。
- **模型增量** Δ_model = regret@3(Mk) − regret@3(模型)，带 CI 与 p。
- **叠加臂**：k 条探针 + 低秩重排后，在重排序上跑 SH6-3-3 与 SH10-4-3。淘汰规则同 S2 `_headroom_four`：按 seed 0 的 q25 / q50 淘汰，按 end0 选，用 end1 评。
- **成本 = 轨迹续跑累计**：每个配置按它走到的最远截点分数计（探针 = b_probe，SH 各级 = 0.25 / 0.5，终选 = 1.0），同一配置不重复计，逐任务求和后取均值。plain 臂 = 探针 + 前 3 终选。
- **基线臂**：任务盲前 3（3.0）、SH6-3-3 与 SH10-4-3 各两种排序（μ 排序 / 先验平均秩），M25（10.5），③（10.5）。全部进同一张成本–regret 表。

### 2.3 判据（先于数据）
- 部署探针数 = 满足以下两条的最小 k（k = 4 @50% 按成本 2.0 参与排序）：
  - (i) ρ_a1 ≥ 0.70；
  - (ii) 它的 plain / SH6 叠加 / SH10 叠加三臂中，至少一臂不被任何基线臂支配。"支配"= 基线成本 ≤ 该臂且 regret@3 ≤ 该臂（点估计）。
- 同时报该臂与"成本不高于它的最贵基线"的源级配对差 [CI]。
- 读数码：**PROBE-K{k}**；若该 k 的 Δ_model > 0 且 p < 0.05，加后缀 **+MODEL**；没有 k 满足则为 **PROBE-DOMINATED**。

## §3 任务 1：配置侧归纳（名单 → 空间）
### 3.1 模型（每个外层折只在训练源上拟合）
- 训练行 = 训练任务 × (shared-30 ∪ 有效 random)；标签 Z；a₁(t) = 折内投影（K = 1 为主，K = 3 为副）。
- **主臂 L**：ridge on [φ, a₁·φ]（= z ≈ μᵀφ + a₁·wᵀφ，即 field 头结构）。α ∈ {1, 10, 100, 10³, 10⁴}，由训练源内层 LOSO 最小化 MSE 选定。
- **诊断臂 μ-only**：ridge on φ（a = 0），用来判断失败出在主效应外推。
- **副臂**：GBDT = HistGradientBoosting on [φ, a₁]（max_iter 300，seed 0）；MLP = MLPRegressor on [φ, a₁·φ]（hidden 64，early_stopping，seed 0）。
- 留出源的 a：主 = S3-A ④ 的 â₁（可部署）；上界 = 真 a₁（留出 shared 标签投影）。

### 3.2 读数
- **(a) 逐任务 Spearman(预测, R0)**，在该任务的有效 random 配置上算（有效数 ≥ 10 才计）。用原始 seed-0 acc，不用钉底 z。报中位数与均值 [CI]，另报只取 R0 前一半的版本。
- **(b) regret@3，共同分母** o_adj(t) = max(end1[argmax end0], max R0 − κ_n σ)（= S2 H_rand_adj 的 oracle）：
  - 30 候选：同一 φ 模型给 shared-30 排序，取前 3，按 end0 选，value = end1；
  - 50 候选：给 shared ∪ random 排序，取前 3，按 seed 0 值（shared 用 end0，random 用 R0）选。value：shared 用 end1；random 用 R0 − κ₃σ（κ₃ = 0.846，扣掉三选一的赢家诅咒）；
  - regret = o_adj − value；Δ50 = regret(50) − regret(30)，带 CI。
- 校准：留出任务上预测前 3 的 random 配置的（预测 z − 实测 z）均值，shared 同报。
### 3.3 判据（主臂 L，留出 a = ④ â₁）
- 两条：S = 中位 Spearman ≥ 0.50；R = Δ50 的 95% CI 上界 ≤ +0.005（非劣效）。
- 读数码：
  - S ∧ R → **SPACE-OK**；
  - S ∧ ¬R → **SPACE-RANK-ONLY**；
  - ¬S 且 μ-only 中位 < 0.50 → **SPACE-MU-FAIL**；
  - ¬S 且 μ-only ≥ 0.50 → **SPACE-B-FAIL**。
- 副臂与真 a₁ 臂只报，不改读数码。
- SPACE-OK 的含义只是"在均匀样本上成立"，是 Ks + 进化适应度的必要条件，不是充分条件：EV1 里任务盲比较器在进化搜索下的高估从 +0.35 升到 +0.81，那部分只能由 S5 的 H_search 检验。

## §4 任务 2：名单外净空归属
- 每任务 ext_adj = max R0 − κ_n σ − o_cat，o_cat = end1[argmax end0]。
  - **E0** = {ext_adj > 0}（S2 定义，主）；
  - **E2** = {ext_adj ≥ 2σ}（副）；
  - σ 敏感性版本：σ 换成 160 任务的中位 σ 后重算 E0。
- 负端 = S2 反向四源（Semg / Ethanol / CinC / SCP1，轴得分 < −1），56 任务。连续版：a₁(t)（全池投影）。
- 统计：
  - P(E | 负)、P(E | 正)；富集比 = P(E | 负)/P(E) [源聚类 CI]，上限 2.86；
  - **源级精确置换检验**：C(17, 4) = 2,380 种分组，检验"负端源的平均份额 − 正端源的平均份额"，单侧；
  - Spearman(a₁, ext_adj)，任务级与源级各报；
  - 每组的 mean ext_adj 与 mean max(0, ext_adj)；每组的 σ 中位。
- 判据：
  - 富集比 ≥ 2.0 ∧ 置换 p < 0.05 → **HEADROOM-NEG**；
  - 富集比 ≥ 2.0 但 p ≥ 0.05 → **HEADROOM-NEG-WEAK**；
  - 否则 → **HEADROOM-UNIFORM**，并报全池名单外均值增益。
- 不预设"与 AutoCTS++ Table 13 饱和对齐"的结论（原文未核）。
