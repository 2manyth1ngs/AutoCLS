## §1 E 可预测的偏好轴（每折只在训练侧拟合）
- **偏好残差** R：shared-30 within-task z 去掉训练侧配置主效应、再按任务去均值（84.residual，与 SVD 轴同源）。
- **E 特征** U：sh4 / pt4 / pt4+sh4（任务均值嵌入 PCA，折内训练侧拟合与标准化，同 S3-L）。
- **降秩回归（RRR）**：C = (UᵀU + λI)⁻¹UᵀR（训练行、U 与 R 在训练侧中心化）；对拟合值 UC 做 SVD，取前 K 个右奇异向量 Q_K。
  - 预测坐标 â(t) = U(t)·C·Q_K；
  - 真实投影 a(t) = R(t)·Q_K（留出任务用自己的标签，只作上界）。
- **选择**：(E, λ, K) 按训练侧"留一个源"的残差解释方差 EV = 1 − Σ‖R − R̂‖² / Σ‖R‖² 选最大，R̂ = â·Q_Kᵀ。网格 λ ∈ {0.1, 1, 10, 10², 10³, 10⁴, 10⁵}，K ∈ {1, 2, 3}；平局取小 K、大 λ。同时报现行做法（SVD 轴 + 逐分量岭回归）同口径的 EV 作对照。
- **比较器训练用的坐标**：
  - **EP**（可部署）：训练侧任务用留一个源的 out-of-fold â，留出与搜索用全训练侧拟合的 â；
  - **ET**（上界）：真实投影 a。
  - 各坐标按训练侧标准差标准化。

## §2 比较器（重训）
- 结构同 S3-I 的轴瓶颈比较器，k = 所选 K；两种（EP / ET）各 seed 0–4 × 6 折 = 60 次。
- 标签 = 原标签 + S3-G 与 S3-J 的本折扩充（按配置去重合并）；训练制度同 S3-I 第一段（L4 加权 BCE，Adam 1e-4，按验证源损失早停）。

## §3 门与读数
### 3.1 第一道门（零 GPU）：是否存在 E 可预测的轴
- 若所选 (E, λ, K) 的训练侧 EV ≤ 0，停止并报告（E 在本语料里预测不出任何跨源的偏好方向）。
### 3.2 第二道门（排序）：新轴是否让 E 传得更多
- 用 EP 比较器算留出排序：R1 目录内 regret@3（56 任务）、R2 搜索区域池内 regret@3 与 Spearman（48 任务，池同 S3-K）、R3 random-20 Spearman。另算同一比较器置零坐标（EP-Z）与 ET。
- **过门条件**：EP 的 R2 池内 Spearman > 0.376（S3-K 中现行部署 P 的值），且比 EP-Z 高 ≥ 0.02。不过门则停止，不上搜索。
### 3.3 搜索（过门才跑；48 任务，λ = 1，采样 / 进化种子同前）
- 臂：**EP-lcb**、**EPX-lcb**（换源 E 经同一映射）、**ET-lcb**（上界）。对照：S3-J 的 A′ / O′ / B′、目录前 3、R。
- 两种读法：3 选 1、3 条平均。
- **读数码**：
  - **E 段**（EP − B′）：3 条平均 ≥ +0.010，且任务级 Wilcoxon p < 0.05，且 ≥ 4/6 源为正，且 3 选 1 > 0 → **S3M-E-WIN**；3 条平均 ≤ −0.010 且 p < 0.05 → **S3M-E-HURT**；否则 **S3M-E-NULL**。
  - **+GAIN**：3 条平均的 EP − A′ ≥ +0.005，且 p < 0.05，且 ≥ 4/6 源为正（新轴比 S3-J 的现行部署好）。
  - **+CONTENT**：3 条平均的 EP − EPX ≥ +0.005，且 p < 0.05，且 ≥ 4/6 源为正。
- 门不过时的读数码：**S3M-NO-AXIS**（第一道门停）/ **S3M-RANK-NULL**（第二道门停）。
