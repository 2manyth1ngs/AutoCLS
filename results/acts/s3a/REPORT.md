## §0 诚实账
1. 协议 §0 声明：上一会话的四组仪器核查数有两项没能逐位复现——MS 0.801 / 0.225 本会话算出来是 0.754 / 0.175，源内份额 0.20 算出来是 0.27（`analysis.json` 里是 0.29，因为这里的 a₁ 是 LOSO 投影）。协议按本会话复算的数执行。秩解释量和轴 ρ（0.988）都复现了。
2. 协议相对设计原文改了一处：设计里的 ② 组（终点 h_t / failed / σ_task）改成诊断组、不进门。原因是这三个量要用全部 60 个终点来算，部署时等于已经把整个目录测完了，而且和 regret 真值同源。另设可部署的 ②′。
3. ②′ 的 ρ = −0.58（CI 整段 < 0）**不是反向信号**，而是 LOSO ridge 的已知偏差：特征没有信息时，预测会收缩到训练折均值，而训练折均值不含留出源，于是和留出源的真值反相关。源内 ρ −0.18，Δregret ≈ 0，都支持这个读法。
4. 符号约定：每折的 b₁ 对齐到全池的 b₁（这是读数约定，预测对符号等变），单测已固定 b_ref 验证无泄漏。
5. 事后项：只有 §3 的 SH 成本对照（`posthoc_sh.py`，在看过 `tables.md` 之后写的）；其余都是预注册读数。

读法：
- **低秩模型的天花板是真的**：真 a 代回后 regret@3 0.021 → 0.000，目录内任务感知余量全部可以由 K ≤ 3 的轴坐标解释（P1 ✓）。

- K：③ 在 17/17 折都选了 K = 3（P8 ✗）；④ 在 K = 1 和 K = 3 之间摇摆（8/7），K 固定为 1 时 Δ 最大（+0.010 / +0.007 / +0.007）。

## §7 下一步（按协议进 S3-B；有三处待拍板）
