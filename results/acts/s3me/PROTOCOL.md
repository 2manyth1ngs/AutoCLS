# WP17-ACTS S3-ME PROTOCOL：源专家混合（E 只做相似度）——零 GPU 线性版验证

**会话定位**：
- 用户 2026-10-01 要求深入核查 T-CLSC 内部架构与 E。核查发现（本会话数据）：
  - ① E_pt 前两个主成分由数据集身份决定（η² 0.84 / 0.82）。去掉共有偏好后，按 E 找到的最像数据集，其特有偏好与自己的 Spearman 只有 +0.09（E_pt）/ +0.10（E_A）/ +0.12（两者拼接），随机 −0.05，上限 +0.55。
  - ② field 头里 E 经 w(E) 自由调整 116 个字段权重，自由度远超数据能支撑的程度。
  - ③ E_pt 不看标签。
  - ④ E 混入 TS2Vec 训练次数与窗口长度的流程差异。
- 改法：**源专家混合**——每个源学自己的字段权重，E 只用来算目标与各源的相似度权重。本协议先用线性（岭回归）版在 17 源留一源上零 GPU 检验，过了再改 T-CLSC 并上部署。

产物 `results/acts/s3me/`；代码 `scripts/114_acts_s3me.py`；单测 `tests/test_acts_s3me.py`。零 GPU。

## §1 模型（线性版，对应 T-CLSC 的 field 头结构）
对任务 t 的配置 c（binned 向量 x_c ∈ R¹¹⁶），目标 = 任务内标准化的 L4 标签 z_t(c)：
- **任务盲主项：** s₀(c) = β₀·x_c，用全部训练任务的配置做岭回归（α 0 = 10）。
- **源专家：** 每个训练源 j 用自己所有切片的残差 z − s₀ 做岭回归，得 w_j（α_w ∈ {1, 10, 100}）。
- **目标预测：** s(c) = s₀(c) + γ · Σ_j π_j · w_j·x_c，其中 π = softmax(sim_j / τ)。
  - sim_j = 目标任务 E 与源 j 平均 E 的余弦，E 按训练任务的均值、标准差标准化；
  - τ ∈ {0.05, 0.1, 0.2, 0.5, 1}，γ ∈ {0, 0.25, 0.5, 0.75, 1}。
- **超参选择：** (α_w, τ, γ) 在训练源内部做留一源内层选择，准则 = 内层留出任务上预测与 z 的 Spearman 均值（全部配置）。平局取较小 γ，再取较大 τ、较大 α_w。

## §3 评估（17 源留一源，外层留出源的全部切片，共 160 任务）
- **M1** regret@3：shared-30 上按预测取前 3，种子 0 选、种子 1 评（= 84.regret_at_k）。
- **M2** 全部配置上预测与 z 的 Spearman（逐任务，取均值）。
- **M3** random-20 上预测与种子 0 真值的 Spearman（全空间代理）。
- **M4** 残差 Spearman：(s − s₀) 对 (z − s₀)，只看 E 带来的那部分。
- 源级 bootstrap 95% CI（按源重采样）。

## §4 门与读数码（主臂 ME_ptA）
- **E 起作用（对 UNIFORM）：** M2 与 M4 都高于 UNIFORM。
- **不添乱（对 BLIND）：** M1 ≤ BLIND + 0.002 且 M2 ≥ BLIND − 0.005。
- 读数码：
  - 两者都成立且 M1 < BLIND → **S3ME-GO**；
  - 两者都成立但 M1 ≥ BLIND → **S3ME-SAFE**；
  - “E 起作用”不成立 → **S3ME-E-NULL**；
  - “不添乱”不成立 → **S3ME-HURT**。
- 显著性只作描述（用户 2026-10-01：任务特异可不显著，按 AutoCTS++ 方式对比消融臂）。
- GO 或 SAFE → 按同结构改 T-CLSC（源专家 field 头），接 S3-Y 部署流程；否则按读数报告。
