# WP17-ACTS S3-L PROTOCOL：让 E 的 a₂ 传到比较器——E → 坐标映射的筛选 + 一次搜索

**会话定位**：S3-K 显示：
- 前两维坐标就能兑现约九成的任务感知增益（池内 Spearman 91%），第三维贡献小；
- E 对 a₂ 有信息（留出任务秩相关 0.44），但 E → 坐标的岭回归按"坐标 MSE"选正则，把 â₂ / â₃ 压成了 0（幅度比 0.000 / 0.011），â₁ 也只有半幅度（0.52）；
- 比较器实际上只收到半个 a₁。

用户 2026-09-27 拍板开始下一步：改 E → 坐标的映射（按下游排序选正则 + 幅度校准 + 换 / 合并 E 来源），选出最好的换进 S3-J 的 I′ 比较器（不重训）上一次搜索。E 支路保留。

产物 `results/acts/s3l/`；代码 `scripts/99_acts_s3l.py`；单测 `tests/test_acts_s3l.py`；服务器 `scripts/pa_pod/acts_lab_run_s3l.sh`。

## §0 已看过的读数（如实声明）
- S3-I / S3-J / S3-K 全部读数，包括 S3-K 各坐标条件在留出任务上的 R1 / R2 / R3 与幅度比。
- **没看过**：任何新映射在留出任务上的读数。
- 已知的乐观偏差：DS 映射的正则强度按训练侧"留一个源"的下游读数选（7 个候选取最好），用同一读数比较 DS 与 MSE 映射时，DS 有轻微的选择乐观。留出任务上的读数与搜索不受影响。

## §1 映射候选（4 种 E × 2 种映射 = 8 个；全部只在折内训练侧拟合）
- **E 来源**（S3-B 已算好的任务均值嵌入，PCA 在折内训练侧拟合，再按训练侧标准化）：
  - **sh4**：每折共享 TS2Vec 均值，PCA 4 维（= S3-H / I / J 用的 E）；
  - **sh8**：同上，PCA 8 维；
  - **pt4**：每任务 TS2Vec 均值，PCA 4 维；
  - **pt4+sh4**：两者拼接。
- **映射**：
  - **MSE**（现行）：逐分量岭回归，α 按"留一个源"预测坐标的 MSE 选（84.choose_alpha）；
  - **DS**（下游）：三个分量共用一个 α，按训练侧"留一个源"的**下游排序读数**选；再对每个分量做幅度校准：â_k ← β_k·â_k，β_k 是训练侧留一个源的 out-of-fold 预测对真实坐标的过原点回归斜率，截断到 [0, sd(a_k)/sd(â_k)]（校准后幅度不超过真实坐标）。
- 两种映射的 α 网格都是 {0.1, 1, 10, 10², 10³, 10⁴, 10⁵}。
- **下游排序读数**：用该折 I′ 集成，把训练侧某个源的任务坐标换成 out-of-fold 的 â，算 shared-30 上胜场与两种子均值的 Spearman，对任务取平均。I′ 在训练时见过这些任务的真实坐标，所以这个读数衡量的是"â 能多好地替代 a"。
- **部署**：集成成员 m 的映射在训练源 bootstrap m 上重拟合（α、β 取全样本所选），与 S3-I / J 相同。

## §2 选择规则（先于数据）
- 8 个候选里，取训练侧下游读数（6 折平均）最高的一个，记为 **M★**；平局取字典序最小的（E 来源, 映射）。
- 若 M★ 就是现行的 sh4-MSE，则不上搜索，只报筛选结果。

## §3 读数
### 3.1 筛选（零 GPU）
- 每个候选：训练侧下游读数；留出任务上的 R1（目录内 regret@3，56 任务）、R2（搜索区域池内 regret@3 与 Spearman，48 任务，池同 S3-K）、R3（random-20 Spearman）；以 S3-K 的 Z / T 为两端算兑现比例；â 各分量的幅度比与留出秩相关。
### 3.2 搜索（M★；48 任务考卷，I′ 比较器不变，λ = 1，采样 / 进化种子同前）
- **A″-lcb**：M★ 读出的坐标；**AX″-lcb**：换源 E 经 M★ 读出的坐标。对照：S3-J 的 A′ / O′ / B′、目录前 3、R。
- 两种读法：3 选 1（seed 0 选、seed 1 评）、3 条平均（两种子均值）。
- **读数码**：
  - **E 段**（A″ − B′）：3 条平均 ≥ +0.010，且任务级 Wilcoxon p < 0.05，且 ≥ 4/6 源为正，且 3 选 1 > 0 → **S3L-E-WIN**；3 条平均 ≤ −0.010 且 p < 0.05 → **S3L-E-HURT**；否则 **S3L-E-NULL**。
  - **+MAP**：3 条平均的 A″ − A′ ≥ +0.005，且 p < 0.05，且 ≥ 4/6 源为正（新映射对现行映射的改进）。
  - **+CONTENT**：3 条平均的 A″ − AX″ ≥ +0.005，且 p < 0.05，且 ≥ 4/6 源为正。
- 描述项：A″ 占 O′ − B′ 增益的比例、自提名高估、逐源表。
