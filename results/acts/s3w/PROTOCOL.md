# WP17-ACTS S3-W PROTOCOL：保守式比较器（训练时内置全空间搜索）——以部署精度为目标

**会话定位**：
- S3-V 显示部署精度的缺口在全空间搜索的提名：验证集选择几乎无损，但 FULL 前 3 提名的 TEST 上限只有 0.592，低于 TS2Vec 0.624。
- 源侧多次看到比较器对自己提名的配置高估 0.10–0.20（S3-G / H / J），真跑回灌一轮能把高估压掉一半。
- 用户 2026-09-28 拍板：从比较器内部解决，**搜索必须保持全空间**（不在名单上排序）；目标是提升部署层精度。
- 做法（借 COMs，Trabucco et al. ICML 2021 的保守目标模型）：训练时每个 epoch 用当前比较器在训练任务上跑一次与部署同款的全空间搜索，把搜出的“模型看好但无标签”的配置对已标配置的胜率拉向数据里的基准率。部署侧搜索、选择、评估与 S3-V 逐项相同。

产物 `results/acts/s3w/`；代码：

## §1 保守项（只改训练，结构、标签、早停与 S3-R′ 相同）
对训练任务 i，每个 epoch 开始时：
1. **内层搜索（与部署同款、规模缩小）**：本 epoch 均匀采样 2,000 条配置（结构性剪枝同 acts.yaml，各任务共用）→ 当前模型、任务 i 的 E（全部窗口）下分块循环赛取 10 → 进化 3 代（kp 10、p1 0.8、p2 0.2）→ 循环赛前 5 条 = **对抗集 A_i**（与任务 i 已标配置同键的剔除）。
   - epoch 0 为全部训练任务生成；之后每个 epoch 轮换刷新 1/3 的任务，其余沿用上次的对抗集。
2. **基准率** t(c)：对任务 i 的每条参考配置 c（训练用、非失败的已标配置），t(c) = 该任务训练用 random 配置中 L4 值高于 c 的比例（平局记 0.5）。含义：一条没有标签的均匀随机配置胜过 c 的经验概率。
3. **保守损失**：每个批次里的每个任务，从参考配置中随机取 ≤ 16 条，与 A_i 组成双向配对：
   - P(x ≻ c) 的目标是 t(c)，P(c ≻ x) 的目标是 1 − t(c)；
   - 软标签 BCE，任务内取均值，批内对任务取均值；
   - **E 取值分离（detach）**，保守项不改 Set-Transformer，只约束比较头与配置支路。
4. 总损失 = S3-R′ 主损失 + α × 保守损失。α ∈ {0.3, 1, 3}，逐折按 §2 内层准则选一个。

## §2 扩充池与 α 选择
- **扩充池**：S3-G、S3-J 的 `search_aug` 提名中有 seed-0 真值的配置，按（任务，配置键）去重，剔除与该任务已标配置同键者。挂在各源的 a00 / a04 任务上。
- **扩充池 regret@3**：
  - 池 = 已标配置（shared-30 + random-20）∪ 该任务扩充配置；
  - 真值统一用 seed-0 终点（shared 用 end0、random 用 R0、扩充用 seed-0 真跑）；
  - 比较器（3 种子 P 均值）循环赛取前 3，regret = 池内最好 − 前 3 最好。
- **高估**（= S3-G 定义）：扩充配置的预测胜率（3 种子 P(x ≻ shared-30 各条) 均值）减去真值胜率（seed-0 真值高于 shared-30 end0 的比例）。
- **α 选择（逐折、逐臂）**：只用该折训练源上的扩充任务（不含留出源），取扩充池 regret@3 均值最小的 α；与最小值相差 ≤ 0.002 的取较小 α。
  - 这是只在训练源上的内层验证。扩充标签只作验证与考卷，**不进训练**。

## §4 门与读数码
- **主门（部署，CONS 6 集 3 种子 TEST 均值）**：
  - > InfoTS_s 0.6468 且 > TS2Vec 0.6243 → **S3W-BEATS-BOTH**；
  - 只 > TS2Vec → **S3W-BEATS-TS2VEC**；
  - ≥ S3-V FULL 0.5987 + 0.010 → **S3W-UP**；
  - ≤ FULL − 0.010 → **S3W-DOWN**；
  - 否则 → **S3W-FLAT**。
- **后缀 +E**：CONS ≥ CONS_B + 0.010。
- **后缀 +MECH（机制门，留出 6 个 UEA 源的 a00 / a04 共 12 任务）**：CONS 的扩充配置高估 ≤ FULL − 0.05，且扩充池 regret@3 ≤ FULL + 0.005。
- 描述项：
  - 逐数据集表；逐数据集胜 TS2Vec / InfoTS_s 数；
  - 前 3 提名 TEST（种子 0）上限 / 平均；选择损失；
  - 各折选中的 α；
  - 训练中对抗集的预测胜率与基准率轨迹；
  - CONS_B 的机制门读数。
- 6 个数据集、3 种子，不做显著性声明；臂间差 < 0.01 视为持平。
