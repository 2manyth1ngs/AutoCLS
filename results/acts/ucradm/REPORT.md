读法：
- **可靠性远高于 S1″ 池**：40 个任务的 ρ_t 中位 0.86、最低 0.37（EOGH_a03，窗 (600, 994) × n 304）；S1″ 13 源里 HMD / SCP2 是 0.25–0.61，UWave_a00 0.17。单变量集的 σ_task 0.003–0.035（S1″ 试点 0.006–0.013 同量级），噪声不是这批源的问题。
- **护栏离门很远**：h_t 全部 ≥ 0.24，与 S1″ 被拒的 PS（0.06–0.13）/ Ethanol（0.06–0.25）不是一个量级；ShapesAll / Adiac / NonInvasive1 这类多类集 h_t 0.4–0.8。
- **v2 尺子复算（事后）**：同一批数据按 S1″ v2 三条（前一半 ρ ≥ 0.40 ∧ 净占比 ≥ 0.25 ∧ IQR/σ ≥ 2）只放行 CinCECGTorso / ShapesAll 2/10——净占比在 8 个源上 0.03–0.24。与 S1″ REPORT §4.1 同判：(ii) 净占比在 4 行同质任务上系统性偏低，不是源的问题。
- **failed（探针地板口径）**按 τ 0.01 / 0.1 / 1.0 = 0.45 / 0.45 / 0.78（S1″ 0.43 / 0.51 / 0.75），随 τ 单调的"高温失败"在单变量集上同样存在；LargeKitchen 0.86（两种子都超地板中位只 3）是 3 类近 chance 型切片 + 高温失败叠加，但它的 h_t 0.28–0.49 与 ρ_t 0.67–0.93 仍过门。

## §4 多样性（协议 §1.7，只作读数）

- ρ(源画像, S1″ v3′ 池均值画像)：0.49–0.87，Semg 0.22；UCR 十源两两 ρ 中位 0.60、最低 −0.09。
- 合池（11 + 10）源间 / 源内秩方差 **0.60 / 0.40**；参照池 0.59 / 0.41；UCR 池单独 0.57 / 0.43。合池 agree：UCR 源 0.65–0.93（Semg 0.32），S1″ 源保持原样（Ethanol 0.02 / SCP1 0.39 仍是反向源）。
- 事后：十源两种子均值平均秩前 3 的 τ 全部 ∈ {0.01, 0.1}（a04011c2 / 2a667428 / 9e289c74 / 018d72f2 / ce013ded 五条配置轮流占前三），与 S1″ 切片口径的赢家 τ ≤ 0.1 一致。
- 读法：UCR 十源带来的是"更多可靠标签的数据集"（n 11 → 21），偏好序与现池同向；对 S2 的意义在 A′ 的分界变量（训练侧数据集数），不在源间偏好差异。想要反向源（Ethanol / SCP1 型）得在别处找。

## §5 读法与下一步（待用户拍板）

1. **准入层**：v3′ + 护栏在 UCR 十源上 10/10 放行，尺子本身在 S1″ 13 源上已有标定（拒 PS / Ethanol / HMD / SCP2）；同一尺子下 ACTS 可用源池 = 11 + 10 = **21**（≥ 方案的源池底线 7 三倍）。1,200 条 shared 标签（两种子）对同口径 S2 直接复用。
2. **S2 若铺**：(a) 源池 21、每源 16 任务 × (shared-30 + random-20)（UCR 十源的 random 尚未采）；(b) 靶集须处理 XFER-DEAD——UCR 进源池后，靶要么含 UCR 集（混池 LODO），要么把"UEA 官方靶不伤"设成门；(c) E 消融门设在去掉集内主效应的残差上（S1′ 教训）。
3. **B 档是否补测**：Fish / Haptics / InlineSkate / Mallat / Yoga 等 12 个（≈ 240 格 / 源 ≈ 5 GPU-h / 源）——本轮 10/10 全过说明零 GPU 筛表的 A 档判据偏保守，B 档过门概率高；但它们不会增加偏好多样性（+SAME 读数），只增加 n。
4. **工程**：共享数据盘会被写满（S1″ 两次、本轮一次），ACTS 实验室三件套一律把输出 symlink 到根盘（本轮起 run 脚本支持 `LOG=`）；`pkill -f` 只在服务器脚本文件里用；cost_model 对 4090 争用环境低估 4–5×。
