**会话定位**：
- S3-V 显示部署缺口在提名：FULL 前 3 提名的 TEST 上限 0.592，低于 TS2Vec 0.624。
- 用户 2026-09-28 指出：2 万候选里很可能有好策略，问题可能是排序器把好的排低、把差的排高，而不是“偏离名单”。
- 用户拍板：把 6 个数据集上已有的 21 条全空间提名全部全跑，分清两件事：
  - **T-CLSC 在这些提名之内排序不行**；
  - **还是全空间搜索压根找不到好配置**。

产物 `results/acts/s3x/`；代码 `scripts/110_acts_s3x.py`（候选池 / 计划与复用 / 比较器打分 / 读数）；单测 `tests/test_acts_s3x.py`；服务器 `scripts/pa_pod/acts_lab_run_s3x.sh`（排在 S3-W 之后）。

## §0 已看过的读数（如实声明）
- 21 条提名（每个数据集）= S3-V 五臂（FULL / w/o Set-Transformer / w/o TS2Vec / w/o shared / 任务盲）× 前 3 + S3-C-D 两臂（A 严格复现 T-CLSC / D 任务盲比较器）× 前 3。
  - 本会话已核：6 个数据集上各自互不相同，与 shared-30 及训练中任何已标配置重合 0 条。
- 已看过它们的**种子 0** 官方 TEST：
  - 逐数据集 21 条的均值 / 中位 / 最好：HW 0.436 / 0.431 / 0.542，PS 0.181 / 0.175 / 0.222，UWave 0.884 / 0.894 / 0.922，Cricket 0.911 / 0.931 / 0.972，Ethanol 0.266 / 0.270 / 0.316，SCP1 0.779 / 0.799 / 0.860；
  - 随机取 K 条按种子 0 真值选最好：K = 3 → 0.610、6 → 0.624、10 → 0.632、15 → 0.637。
- 已看过 S3-V 五臂的 D_val 读数与各臂选中配置的 3 种子读数。
- 已看过留出 56 任务的好半区判对率（排序器 0.52、同源其他切片 0.543、E_pt 近邻 0.548、跨任务先验 0.505）。
- **没看过**：任何配置的种子 1 / 2（除 S3-V 各臂选中者）；S3-C-D 那 6 条的 D_val；任何比较器在 21 条池内的打分。

## §1 候选池与运行
- **池**：每个数据集上述 21 条（`pool.json` 冻结；记录每条来自哪次搜索）。
- **运行（官方口径，与 S3-V 逐项相同）**：每条配置
  - 完整官方 TRAIN 训练，种子 0 / 1 / 2，报 TEST；
  - 官方 TRAIN 内分层 20% D_val，种子 0，报 D_val 准确率。
- **复用**：
  - S3-V 已跑格按缓存键原样复用；
  - S3-C-D 已跑的种子 0 官方格来源标记不同，按（任务，配置键，种子，评估口径）对上后复用；
  - 其余新跑，约 228 格。
- **真值**：T3 = 3 种子 TEST 均值。

## §2 比较器池内打分（服务器，零训练）
- 7 个比较器在每个数据集的 21 条池上各算一次概率矩阵，取循环赛胜场作为打分：
  - FULL、w/o Set-Transformer、w/o TS2Vec、w/o shared、任务盲（均为 S3-V 所用的 3 种子集成）；
  - A、D（S3-C 单模型）。
- 目标 E 与 S3-V / S3-C-D 相同（只用官方 TRAIN）。
- 附加（不进门、只描述）：S3-W 跑完后，CONS / CONS_B 也在池上打分。

## §3 读数与读数码
- **R1 找得到吗（主）**：诚实池内最好 = 每个数据集按种子 0、1 的均值在 21 条里选 1，报它的种子 2 TEST，6 集取均值。
  - 同时报按 T3 选的乐观值，以及各臂自己前 3 里的最好者。
  - 诚实值 > TS2Vec 0.6243 → **FIND-OK**；
  - > S3-V FULL 0.5987 → **FIND-PARTIAL**；
  - 否则 → **FIND-FAIL**。
- **R2 排得对吗（主：FULL）**：
  - 池内 regret@3 = 池内 T3 最好 − 比较器前 3 条里 T3 最好；
  - 随机基线 = 21 选 3 的期望 regret（精确计算）；
  - FULL 的池内 regret@3 ≤ 0.5 × 随机 → **RANK-OK**；≥ 0.8 × 随机 → **RANK-FAIL**；其间 → **RANK-WEAK**。
- 读数码 = `S3X-<FIND>+<RANK>`。
- 描述项：
  - 各比较器的池内 Spearman（打分 vs T3）、池内 regret@3；
  - 自我偏好：各比较器把自己提名的 3 条排进池内前 3 的条数；
  - D_val 排序（测量参照）的池内 regret@3 与按 D_val 选 1 的 T3；
  - 逐数据集表。
- 6 个数据集，不做显著性声明。
