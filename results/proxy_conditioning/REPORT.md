# 代理条件化 REPORT：逐格零训练代理判负——交互残差零信号，pooled 大相关是天花板伪相关

**一句话结论**：决定性检验 D1x（扣除任务/CLS 两主效应后的交互残差 Spearman）**ρ=+0.0485、
置换 p=0.2021，判负**。而未残差化的 pooled 相关高达 **ρ=−0.531**（仅扣 CLS 主效应 −0.667）
——**又大又反向**，机制经 post-hoc 核实为**天花板伪相关**（corr(g1_clean, R')=+0.780、
corr(fid, g1_clean)=−0.811）。协议预注册的陷阱对照在此兑现：**若无残差化，这个 −0.53
会被误读成"代理有强预测力"**。看门层安慰奖 D2x 同样不过（ρ=−0.294, p=0.153），格级判别
AUC=0.536 ≈ 随机。逐格代理家族在 @290 + 共享 10 CLS + 随机初始化编码器口径下关闭。

## §2 第 0 步：代理自身交互份额 → **琥珀**（勉强过杀线）

只看代理不看结果变量（协议 §4）。两因素 SS 分解：

| 代理 | 任务主效应 | CLS 主效应 | **交互** |
|---|---|---|---|
| **fid**（主代理 Δg1） | 0.619 | 0.278 | **0.102** |
| var（InfoTS variety） | 0.110 | 0.629 | 0.261 |
| Δg2 / Δg3 / Δg4 | 0.996 / 0.962 / 0.976 | 0.002 / 0.014 / 0.002 | 0.002 / 0.025 / 0.023 |
| dT（长度变化） | 0.030 | 0.638 | 0.333 |

fid 交互份额 0.102 仅高于杀线 0.10 → 琥珀档（过闸加严：D1x 须 ρ≥0.15，不接受边缘）。
**这已预示结局**：代理 62% 的方差是"哪个任务"、28% 是"哪条 CLS"，只有 10% 在交互；
Δg2/Δg3/Δg4 近乎纯任务主效应（0.96–0.99），对条件化零信息量。

## §3 第 1 步：D1x 决定性检验 → **不成立**

| 读数 | 值 |
|---|---|
| **D1x 交互残差 ρ** | **+0.0485** |
| 置换 p（任务内置换，n_perm=10000） | **0.2021** |
| 判读 | **not_established** |

n=800 格 / 残差自由度 711——此规模下 ρ=0.10 即 p<0.01，**功效不是瓶颈，信号确实不在**。

**陷阱对照（协议 §5 要求必报）**：

| 口径 | ρ |
|---|---|
| pooled（不残差化） | **−0.5308** |
| 仅扣 CLS 主效应 | **−0.6665** |
| 扣两个主效应（D1x） | +0.0485 |

**机制（post-hoc 核实，标注探索性）**：任务级 corr(g1_clean, R'@290)=**+0.780**、
corr(fid, g1_clean)=**−0.811**、corr(fid, R')=−0.774。即：干净几何越好的任务 R' 越高，
而几何越好增强越无从"改善"（Δg1 越负）——**fid 通过基线几何质量与 R' 反向耦合，
与"增强破坏类结构"这个假设机制无关**。协议首句要求兑现：pooled 的 −0.53 **只是重新
发现了任务难度，不是条件化**。

## §4 诊断与敏感性（全部预注册，无一翻盘）

- **S-std**（任务内标准化残差）：ρ=+0.0291。
- **次代理**：var ρ=−0.166 (p=1.000)、Δg2 −0.041 (0.906)、Δg3 +0.060 (0.161)、
  Δg4 −0.055 (0.994) —— 无一显著，多数方向为负。
- **长度归因诊断**：ρ(ΔT 残差, fid 残差)=+0.126；把 ΔT 偏出后 D1x 由 +0.0485 变 +0.0481
  ——**长度不是驱动因素**（PX6 押错，先验 40%）。§2 偷看披露的 SCP2 反升现象未构成系统性混淆。
- **D2x 数据集级（看门层安慰奖）**：ρ=**−0.294**, p=0.153 (n=25) → **不过**（线为 ρ≥0.5）。
- **D3x 格级判别**：AUC(destroy)=**0.5356**（231/800 破坏格）≈ 随机。
- **任务内相关分布**（post-hoc）：80 个任务各自 10 CLS 上 corr(fid, R') 中位 **+0.106**、
  64% 为正、四分位 [−0.147, +0.263]——**有微弱正向倾向但经正规检验不成立**。
  逐数据集极值（SAD +0.582 / USC-HAD +0.456 / NIFECG −0.480 / MotorImagery −0.276）
  **每格仅 2 任务，按 n=2 禁令不得作任何依据**。

## §5 一个廉价读数的去魅（post-hoc）

`g1_clean`（随机初始化编码器上的零训练 NCC 几何）预测任务级 R'@290 达 ρ=+0.780，看似
可当免费的可评性打分器。但它与既有 iters=0 基线 `base_mean` 相关 **ρ=+0.792**，
而 `base_mean` 自己预测 R' 更强（**ρ=+0.942**）；扣除 base_mean 后 g1_clean 的偏相关仅
**+0.153**。→ **它是既有基线的更弱冗余版本，不构成新能力**，看门层无需改动。

## §7 含义

1. **任务级条件化的三种形状全部走完**：固有特征（`wide_panel` D1w p=0.994）、
   行为测量/转导补全（`behavior_recon` 闸门 fail）、逐格零训练代理（本目录 D1x p=0.202）。
   三条路读的分别是主效应、任务间相似度、逐格交互，**形状各异而结论一致**。
2. **本次失败不可归因于标签噪声**：代理是确定性计算（5 种子均值，无测量噪声），
   而其自身交互份额只有 0.102、与结果交互的对齐只有 0.049。即便结果变量完全无噪，
   这样的对齐度也解释不了 0.448 的交互份额。→ **C 升级路径（k=5 重测）不再是本条线的
   自然续集**：它能揭开被噪声掩盖的信号，但这里的问题是代理端没有对齐的信号。
3. **方法学产出（可写进论文 methods/limitations）**：pooled −0.53 → 残差化后 +0.05 的
   反转，是"未扣主效应的相关会把任务难度误读成条件化能力"的干净展品；本项目的两向
   残差化判据可作为同类主张的检验模板。
4. **未试变体（如实登记，不推荐）**：本探针用**随机初始化**编码器（零泄漏、零成本、
   最可部署）。冻结共享 TS2Vec 空间上的同款代理未测；但 MX-1b 的 G 组（干净数据的
   TS2Vec 类几何）在任务级已垮（`gate2_pilot_b` 方向负、ρ≈0），两个表征空间同向失败，
   该变体先验低。
